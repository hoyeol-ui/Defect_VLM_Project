## 2. 가장 먼저 고쳐야 할 설명

### 2.1 초기집합과 횟수

R0는 공통 무작위 초기 10% 집합이다. DINO로 첫 10%를 뽑은 것이 아니다. 그다음 R1~R5에서 원래 표본선택 풀의 약 5%씩 다섯 번 추가한다. 총 예산점은 여섯 개다.

| 구분 | 실제 탐지 학습 실행 수 |
|---|---:|
| 공통 R0 | 2 데이터셋 × 10 선택 시드 × 2 학습 반복 = 40 |
| Random R1~R5 | 2 × 10 × 2 × 5 = 200 |
| DINO R1~R5 | 2 × 10 × 2 × 5 = 200 |
| Entropy R1~R5 | 2 × 10 × 2 × 5 = 200 |
| Full-data | 2 데이터셋 × 2 학습 반복 = 4 |
| 합계 | 644 |

‘Random 220회, DINO 220회’는 공유 실행을 임의로 반씩 나눈 것처럼 보이므로 사용하지 않는다. R0를 포함한 방법별 분석 곡선에는 각각 240개의 평가 행이 있지만, 공유 R0를 중복 실행한 것은 아니다. 학습 1회는 특정 데이터셋·선택 집합·학습 시드·설정의 YOLO 학습 실행이며 epoch와 다르다. 프로토콜은 100 epochs로 설정되어 있다. 실제 완료 epoch는 실행 로그와 구분해 확인한다.

현재 예산 장수는 GC10 161/241/321/401/481/561장, NEU 126/189/252/315/378/441장이다. 선택 시드는 초기집합·선택 경로의 반복, 학습 시드 A/B는 같은 선택 집합으로 학습했을 때의 변동을 보기 위한 반복이다.

### 2.2 세 모델 역할과 거리 분석

- DINOv2는 동결 특징 추출기다. 현재 최종 결함 위치·종류를 예측하는 탐지기는 YOLOv8n이다.
- 최근접 이웃 그림은 **특징 공간의 의미를 설명하는 사후 분석**이다. 실제 DINO 표본선택은 현재 선택 집합에서 가장 멀리 떨어진 후보를 순차적으로 추가한다. 두 분석을 같은 동작처럼 설명하지 않는다.
- DINO 특징은 고정 모델로 한 번 추출해 재사용할 수 있다. Entropy는 직전 라운드의 학습된 YOLO로 남은 후보를 예측해야 점수를 만들 수 있다.
- `x* = argmax_x min_l [1 − cos(z_x,z_l)]`는 기존 표본과의 차이를 보는 점수다. 결함 탐지에 유용한 정도나 추가 학습 이득을 직접 측정하지 않는다.
- Entropy는 NMS 후 각 박스 confidence p의 `−p ln p − (1−p) ln(1−p)`를 이미지 안에서 합한다. p=0.5에서 약 0.693, p=0.9에서 약 0.325다. 박스가 없으면 0이다. 클래스 전체 확률분포의 entropy와 다르다.
- 현재 선택용 예측은 conf=0.25, NMS IoU=0.70, max_det=300이다. AP 평가용 conf=0.001과 혼동하지 않는다. 두 값은 역할이 달라 구별해야 한다.

이 내용을 대본을 보지 않고 예시 하나로 설명하는 연습을 먼저 한다. ‘소량의 라벨에서 추가로 주석할 이미지를 고르는 모의 능동학습’이라는 설정을 함께 설명한다. ‘선택 기준’은 맥락에 따라 ‘표본선택 방법’ 또는 ‘샘플링 방법’, 가로축은 ‘누적 라벨링 이미지 수’ 또는 ‘선택한 학습 이미지 비율’로 정의한다. 용어는 선행연구와 맞추되 라벨링 예산이라는 의미를 잃지 않게 한다.

### 2.3 성능 지표와 베이스라인

기존 original-final CSV에 두 지표가 모두 있다. 아래는 새 학습 결과가 아니라 기존 분할의 탐색 결과다. R5는 각 시드의 A/B 평균을 10개 시드에서 평균했다. Full-data는 A/B 두 번 평균이다.

| 데이터셋 | 방법/예산 | mAP50 (%) | mAP50–95 (%) |
|---|---|---:|---:|
| GC10 | Random R5 | 55.82 | 26.74 |
| GC10 | DINO R5 | 56.73 | 27.33 |
| GC10 | Entropy R5 | 57.00 | 27.96 |
| GC10 | Full-data | 64.77 | 32.04 |
| NEU | Random R5 | 69.93 | 38.02 |
| NEU | DINO R5 | 69.47 | 38.30 |
| NEU | Entropy R5 | 71.23 | 38.50 |
| NEU | Full-data | 76.35 | 42.97 |

GC10 DINO R5의 원 CSV 평균은 27.3346267959%로 소수 둘째 자리 표기는 27.33이다. 기존 발표 이미지의 27.34와 마지막 자리 차이가 있어, 다음 표·그림을 갱신할 때 출처와 반올림을 맞춘다.

교수님 말씀은 비교 가능한 기준을 제시하라는 요구로 반영한다. mAP50의 숫자가 더 크다는 이유로 mAP50–95를 없애지 않는다. 실제로 NEU R5의 mAP50에서는 DINO가 Random보다 낮다. 어느 지표·예산에서도 항상 유리하다고 말할 수 없다.

선행연구 표에는 데이터 배포본·정제 장수·분할·평가 집합·모델 크기·입력 크기·epochs·지표·원문 표 번호를 적는다. 본인 데이터와 조건이 다르면 참고 수치로만 제시한다. COCO 성능이나 다른 데이터셋의 AP를 GC10/NEU의 기대 성능으로 쓰지 않는다. 숫자가 낮은 원인은 지표 차이만으로 확정하지 말고 데이터 정제·박스 매핑·평가 설정·수렴 로그도 확인한다.

현재의 Random+YOLO 곡선은 같은 예산에서의 내부 샘플링 기준선이고, Full-data YOLO는 전체 train 사용 참조다. 문헌의 YOLO 결과는 외부 참고다. 추가 모델 재현은 그 모델을 우리 조건에서 직접 학습한 비교다. 네 가지를 분리한다. YOLOv8n은 반복 비교 비용과 조건 통제를 위한 선택으로 설명할 수 있지만, 실시간성은 측정하지 않았다면 근거로 삼지 않는다. ‘최신 버전이라서’라는 설명도 검증 없이 사용하지 않는다.

### 2.4 nAULC와 paired 차이

nAULC는 예산에 따른 성능곡선의 면적을 예산 구간 길이로 나눈 요약값이다. ‘누적 정확도’ 또는 ‘모든 라운드에서 이긴 비율’이라고 설명하지 않는다.

교수님이 paired 차이 그림의 필요성에 의문을 제기했다고 해서 분석 자체가 잘못됐다고 결론내릴 필요는 없다. 다만 차이만으로는 두 방법의 절대 성능을 알 수 없다. 본문에는 세 방법의 절대 곡선과 시드 간 변동을 먼저 놓고, DINO−Random을 주 비교로 명확히 한다. DINO−Entropy의 paired 차이와 통계는 부록에서 보조로 설명한다. 8/10 시드에서 높았다는 사실만으로 우월성을 확정하지 않는다.

## 3. 첫 번째 로컬 분석: 거리의 의미와 사례 선정

다음 항목은 교수님 요청에 대한 구현 제안이다.

1. **발표에 사용한 네 이미지 간 거리행렬**을 먼저 만든다. 같은 행의 가까운 두 이미지뿐 아니라 silk spot과 water/oil spot의 교차 거리도 함께 보여준다.
2. 자기 자신을 제외한 최근접 이웃과, 사전 고정 ID 규칙으로 뽑은 무작위 짝의 거리 분포를 비교한다. ‘가깝다’가 어느 분포에서 가까운지 보여준다.
3. 공통 라벨 있음/없음의 거리 분포를 사후 비교한다. 다중 라벨에서는 하나 이상 공유한 경우와 라벨 집합이 완전히 같은 경우를 구분한다. 클래스 빈도·중복이 분포에 미치는 영향도 함께 적는다.
4. **대표 표본과 진단 사례를 구분**한다. 대표 표본은 결과를 보기 전에 불투명 ID·seed로 고정하고, 가까운데 라벨이 다른 사례·멀지만 라벨이 같은 사례는 별도 진단 사례라고 명시한다. 좋은 사례만 남기지 않는다.
5. 한 그림에는 기준 이미지, 비교 이미지, cosine 거리, 사후 라벨 관계를 같은 위치에 배치한다. 각 데이터셋에서 기존 두 쌍보다 충분히 많은 예시를 제시하되 전체 비율은 전체 풀 통계로 설명한다.
6. 실제 R1 farthest-first 선택 점수와 선택 순서는 별도로 제시한다. ‘최근접 이웃 분석’과 ‘추가 샘플 선택’을 혼합하지 않는다.

현재 1-NN 라벨 공유율 GC10 81.25%, NEU 99.21%, 라벨 섞기 기준 21.07%, 18.96%는 출발점으로 쓸 수 있다. 이는 독립 평가집합의 탐지 정확도나 DINO의 독점적 우수성을 입증하지 않는다. 일반 CNN과의 비교는 동일 풀·예산·규칙을 고정해 모델 선택 근거를 보강하는 별도 작은 실험으로 둔다.

## 4. 두 번째 로컬 분석: 입력 구성 진단

기존 패키지의 C224/F224 진단은 유지한다. 이전 대화에서 포함한 F518도 비교 후보로 유지하되, 오늘 교수님이 이 세 명칭·규격을 직접 확정한 것으로 적지 않는다.

| 방식 | 확인할 내용 |
|---|---|
| C224 | 기존 RGB → 짧은 변 256 resize → 중앙 224 crop을 재현 |
| F224 | 전체 영상의 종횡비를 보존해 224 입력에 배치. 잘림 감소와 결함 축소가 함께 발생하는지 확인 |
| F518 | 전체 영상 보존 상태에서 입력 크기를 늘려 결함의 입력상 크기를 비교. 실제 크기와 비용을 측정 |

순서: ID·좌표 검증과 일부 C224 재추출 대조 → 실제 박스 보존율·입력상 박스 크기 → 원본/세 입력 비교 → 특징 변화 → 5개 초기집합에서 Random/C224/F224/F518 선택 비교.

기존 패키지의 고정 시드 2026091501~2026091505를 사용하고, 초기 10%·추가 5%는 실제 고정 풀 크기에서 half-up 반올림한다. 같은 시드에서 모든 방법은 동일한 초기집합을 공유한다. 먼저 R1을 비교하고, 여러 라운드가 필요하다면 예산·산출물을 결과 확인 전에 정한다. 기존 캐시의 A/B는 저장된 캐시 라벨이며 선택 시드나 YOLO 학습 A/B와 혼동하지 않는다.

선택 입력에 후보의 정답 박스·클래스를 넣지 않는다. 선택 ID와 순서를 저장한 뒤 GT를 결합해 클래스 구성·박스 보존율을 해석한다. 박스 보존율은 실제 결함 픽셀 보존의 대리 지표다. F518이 C224와 모든 이미지에서 정확히 같은 결함 크기를 갖는다고 전제하지 않는다. 회전·밝기·패치 선택·밀도 보정을 동시에 추가하지 않는다.

완료 산출물: 보존율표, 실제 입력 비교, 특징 이동표, 시드별 선택 교집합·새로 선택/제외된 이미지, 클래스별 선택 구성, 추출/선택 시간과 GPU 메모리, 예비 학습 후보 및 반례.

### AnomalyDINO에 관한 정정

AnomalyDINO는 DINOv2 패치 특징을 사용하는 이상탐지 방법이다. 공식 few-shot 실행은 정상 참조 이미지를 사용한다. 원본 DINOv2가 금속 결함에 맞춰 학습된 모델이라고 설명하거나, AnomalyDINO를 YOLO와 같은 다중 클래스 박스 탐지기로 바로 비교하면 과제와 지표가 달라진다. [논문](https://arxiv.org/html/2405.14529v3), [공식 구현](https://github.com/dammsi/AnomalyDINO).

또한 현재 코드의 중앙 자르기 문제와 ‘DINO가 본질적으로 중앙만 본다’는 모델 특성 주장은 구분해야 한다. 전자는 구현으로 확인할 수 있지만 후자는 이 진단만으로 입증할 수 없다. AnomalyDINO에서 가져올 요소를 정했다면 전처리·패치 표현·점수 집계 중 무엇을 바꿨는지 정확히 적는다. 정상 참조은행을 만들 때 결함 이미지의 정답을 몰래 사용해서는 안 된다.

## 5. 학습과 논문 기여로 연결하는 조건

입력 변경만으로 새로운 알고리즘의 독창성이 확보되지는 않는다. 연구 기여는 **어떤 결함 조건에서 기존 특징 선택이 취약하고, 이를 다루는 변경이 같은 주석 예산에서 어떤 학습 효과와 부작용을 만드는가**까지 연결해야 한다.

진단 후 후보 하나를 고르면 같은 split·초기집합·YOLO 설정에서 Random/C224/후보를 비교한다. 한 데이터셋·한 초기집합·한 학습 시드에서 공통 R0 1회와 R1 3회를 모두 새로 수행하면 4회다. F224와 F518을 동시에 학습 후보로 유지하면 이 계산은 달라진다. 4회라는 숫자를 무조건 적용하지 않는다. 단일 반복은 실행 가능성과 효과의 초기 방향을 보는 예비검사이며 확정 우월성 검증이 아니다.

큰 학습을 시작하기 전에 원본·파생본 그룹과 분할을 정비한다. 기존 분할에서 수행하는 진단은 탐색용으로 명시하고, 이미 열람한 데이터를 새로 나눴다는 이유만으로 미열람 최종 평가집합이라고 부르지 않는다. 최종 비교 방법·주 지표·예산·반복 설계를 고정한 뒤 전체 실험을 수행한다.

오늘 전사본에서 반복 언급되지 않았더라도 **분할 중복 문제와 취약 클래스 하락은 계속 유지**해야 한다. 평균 nAULC, mAP50/mAP50–95, 클래스별 AP, 매 실행·라운드 최저 클래스 지표를 함께 보고한다. 평균 향상으로 취약 클래스 하락을 덮지 않는다.
