# 실험 방법과 학습 횟수

**기존 분할의 탐색 결과를 설명하는 문서입니다. NEU에서 분할 간 내용 중복이 확인됐으므로 독립 검증 결과로 해석하지 않습니다. GC10의 관련 플래그 적용 범위도 별도 확인이 필요합니다.**

## 무엇을 비교했는가

같은 수의 이미지를 라벨링할 때 **어떤 이미지를 추가로 골라야 YOLOv8n의 탐지 성능이 높아지는지** 비교했습니다. DINO는 선택에 쓰는 동결 특징 추출기이며, 최종 결함 위치·종류를 예측하는 탐지기는 YOLOv8n입니다.

| 방법 | 입력과 점수 | 실행 시점 |
|---|---|---|
| Random | 남은 이미지의 불투명 ID에서 균일 무작위 선택 | 매 추가 선택 단계 |
| DINO | RGB → 짧은 변 256 → 중앙 224 → 동결 DINOv2-small → 384차원 pooler 특징 → L2 정규화. 현재 선택 집합까지의 최소 cosine 거리가 가장 큰 후보 선택 | 특징은 전체 선택 풀에서 한 번 추출해 재사용. R1~R5마다 현재 선택 집합에 대해 순차 선택 |
| Entropy | 직전 YOLO가 예측한 박스 confidence p마다 `−p ln p − (1−p) ln(1−p)`를 계산하고 이미지 내 합산 | Rr 선택 직전에 R(r−1)의 **학습 A**의 best.pt로 남은 후보 추론. 선택 집합은 학습 A/B가 공유 |

DINO의 점수는 `d(x,L)=1−max_{l∈L} cos(zx,zl)`입니다. 후보 X가 현재 집합의 이미지들과 0.9, 0.6만큼 비슷하면 점수는 0.1입니다. 후보 Y의 최대 유사도가 0.7이면 점수는 0.3이므로 Y를 먼저 고릅니다. 고른 Y를 즉시 기준 집합에 추가하고 다음 후보의 점수를 갱신합니다. 동점 허용 오차는 1e−12이며 작은 ID를 우선합니다.

Entropy에서 p=0.5인 박스는 약 0.693, p=0.9는 약 0.325입니다. 두 박스가 있으면 합계는 약 1.018이며, 박스가 없으면 0입니다. 이는 **클래스 전체 확률분포의 entropy와 다르며**, 박스 수가 점수에 영향을 줄 수 있습니다. 선택 추론은 conf=0.25, NMS IoU=0.70, max_det=300이고 AP 평가의 conf=0.001과 구별합니다.

## R0~R5와 A/B

- **R0:** 각 선택 시드에서 풀의 약 10%를 무작위로 뽑습니다. 모든 방법이 같은 초기집합을 씁니다.
- **R1~R5:** 원래 풀의 약 5%씩 다섯 번 추가합니다. 여섯 개의 누적 예산점입니다.
- **선택 시드 10개:** 초기집합과 선택 경로의 변동을 봅니다.
- **학습 A/B:** 같은 선택 집합에서 학습을 두 번 반복합니다. 선택 시드와 다른 난수입니다. 캐시 A/B라는 저장 이름과도 다릅니다.
- 각 예산점의 YOLO는 같은 사전학습 가중치에서 새로 시작합니다. 100 epochs, imgsz 640, batch 8, SGD 설정입니다. 기존 기록 644개를 확인했으며, 이번 작업에서 모든 실행의 epoch 로그를 다시 감사한 것은 아닙니다.

| 데이터셋 | 풀 | R0 → R1 → R2 → R3 → R4 → R5 |
|---|---:|---|
| GC10 | 1,605 | 161 → 241 → 321 → 401 → 481 → 561 |
| NEU | 1,259 | 126 → 189 → 252 → 315 → 378 → 441 |

| 실제 학습 실행 구성 | 횟수 |
|---|---:|
| 공통 R0: 2 데이터셋 × 10 선택 시드 × A/B | 40 |
| Random R1~R5: 2 × 10 × 2 × 5 | 200 |
| DINO R1~R5 | 200 |
| Entropy R1~R5 | 200 |
| Full-data: 2 데이터셋 × A/B | 4 |
| **합계** | **644** |

공통 R0를 방법별 곡선에 붙이면 720개 방법·학습·라운드 행이고, A/B 평균 후에는 360행입니다. **644는 통계 표본 수가 아닙니다.** 데이터셋별 선택 시드 10개의 paired 차이를 분석합니다.

## 거리 분석과 평가

최근접 이웃은 특징 공간의 의미를 설명하기 위한 **사후 분석**입니다. 실제 추가 선택인 farthest-first와 목적·방향이 다릅니다. 후보의 정답 라벨·박스를 선택 점수에 넣지 않습니다. 이번 입력 진단도 선택 ID·순서와 해시를 저장한 뒤 GT를 결합했습니다.

nAULC는 R0~R5 성능곡선의 사다리꼴 면적을 예산 구간 길이로 나눈 값입니다. 본문은 **절대 mAP50 / mAP50–95 곡선과 시드 변동**, 부록은 **동일 시드의 DINO−Random 및 DINO−Entropy 차이**를 보여줍니다. mAP는 %, 두 방법의 차이는 %p로 표시합니다.
