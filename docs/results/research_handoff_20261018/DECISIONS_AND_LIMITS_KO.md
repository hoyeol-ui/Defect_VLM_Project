# 현재 판단과 해석의 한계

## 현재 결정

실험은 중단한다. 새 하이퍼파라미터, 샘플링, 모델, 추론 해상도, 추가 audit를 자동 제안·실행하는 흐름을 이어가지 않는다. 다음 MacBook 작업은 문서 읽기와 연구 주장 정리부터 시작한다. 새 GPU 작업은 사용자가 구체적으로 승인한 경우에만 한다.

CM15는 전체 mAP50-95 최고이고 CM20은 inclusion 중심 비교 기준이다. CM15의 water_spot 회복 가설은 실패했다. CM20 채택 목적은 특정 취약 클래스의 유지이며 전체 성능에서 통계적으로 우월하다는 결론이 아니다.

과거 수치는 기존 종합인계(RESEARCH_HANDOFF_COMPLETE.md)의 배경 요약이며 이번 문서 작업에서440/162회 원시 결과를 재감사하지 않았다. 최근 Full-data 표는 포함된 완료 평가 JSON에서 직접 집계했다.

## 직접 확인한 사실과 원인 가설

- 전체 mAP 정체가 모든 클래스의 무변화를 뜻하지 않는다. 개선·하락이 상쇄되는 변화가 있었다.
- Full-data도 현재 조건에서 취약 클래스 AP가 낮지만 데이터셋 절대 상한이나 데이터 증가의 무효를 입증하지 않는다. 고정epoch의 단일 레시피이고 업데이트 수도 달라진다.
- AP50/AP75 차이만으로 회귀 손실,경계라벨,특징표현 중 어느것이 원인인지 확정하지 않는다.
- TP16→10 같은 운영점 변화만으로 동일 GT6개가score임계값아래로밀렸다고단정하지않는다. 위치·클래스·순위·미검출도바뀔수있다.
- AdamW가텍스처를노이즈로억제했다거나SGD가평탄한최적점을찾았다는설명은이자료로입증하지못했다.
- nbs64/batch8이 lr0를1/8로자동축소했다는외부해석은실제코드·로그와맞지않는다. accumulation과weight decay조정이있으며 AdamW4epoch lr은약.0009978이었다.
- close_mosaic20→15가water_spot을복구한다는단순중간값가설은이번실행에서지지되지않았다. 효과의단조성을가정하지않는다.

## 외부 벤치마크와의 비교

DetectionBench 공개 데이터는 Dataset Ninja→Supervisely→YOLO 변환,2300장 중train1840/valid230/test230,seed42 80/10/10분할이다. 좌표보존과이미지변경없음을명시한다. 우리는F518·ANNOTATION_PATCH_v2_0_2·train1604/Dev343의별도동결을사용한다. 개별라벨의동일성이나평가파이프라인의수치동등성은확인되지않았다.

공개 YOLO26s 38.15%와우리최고31.268124%의차이는6.881876%p지만동일조건성능격차로해석하지않는다. 48.78% 논문결과에는라벨정비·이미지특징강화·모델변경이포함돼있다. 그차이를모델또는옵티마이저탓으로만돌리지않는다.

## 주장 범위

다중시드재현·통계적우위·독립test일반화·산업적합성은최근단일dev실험으로확정하지않는다. Dev343은checkpoint선정과실험비교에반복사용됐다. 본확장실험에서독립Test344는평가하지않았다. 과거F518test결과와최근미사용test를같은독립성으로뭉뚱그리지않는다.

산업적합성은mAP하나가아니라미검출·오탐·처리속도·현장분포와연결해야한다. 다만지금은그자료를새로수집하거나평가하는단계를자동시작하지않는다.
