# 저장된 증거 사본

이 폴더는 완료 실험의 JSON/CSV 및 당시 보고서 사본이다. 수치나 원본 내용을 고치지 않았다. 일부 과거 보고서에는 ‘다음 실험’ 또는 ‘아직 실행하지 않았다’ 같은 당시 문구가 있다. **현재 작업 지시는 상위 README_KO.md의 중단 결정**을 따른다.

최신결과는상위RESULTS.json과EXPERIMENT_RESULTS_KO.md다. source별원본상대경로와사본해시는SOURCE_FILES.csv에서확인한다. JSON내Windows절대경로는당시provenance이며Mac실행경로가아니다.
