# 제4장·제5장 Writing Packet v2 수정 이력

## 1. 수정 목적과 범위

이 문서는 `cross_chapter_consistency_audit.md`와 `cross_chapter_consistency_audit.csv`에서 초안 작성 전에 수정이 필요하다고 판정된 항목을 제4장·제5장 writing packet v2에 반영한 기록이다. 수정 대상은 문장 경계, 절 제목, 시간적 지위 표시, 장 간 교차참조 방식에 한정했다.

- 새 claim을 추가하지 않았다.
- 새 수치를 계산하거나 기존 수치를 변경하지 않았다.
- 제4장은 관찰, 제5장은 해석이라는 역할 분리를 강화했다.
- EP01의 최종 통합 문장은 제6장 6.1 마지막에서 한 번만 사용하는 원칙을 유지했다.
- `selector 우월성`, `framework 검증`, `비용 절감 입증`, `산업 benchmark`, `independent production pool 일반화`로 읽힐 표현을 추가하지 않았다.

## 2. 수정 전·후 비교

| 수정 대상 절 | 수정 전 문제 | 수정 후 표현 | 왜 이 수정이 필요한지 |
|---|---|---|---|
| **4.1** | 제목의 `타당성`이 선택 신호의 검증 완료 또는 downstream relevance를 암시할 수 있었다. | 제목을 **후보 선택 신호별 선택 단계 관찰**로 바꾸고, 목적·첫 관찰·한 문장 요약을 native endpoint와 Random 대비 관찰 방향에 한정했다. | 제4장에서는 측정 결과만 제시하고 `타당하다`, `유효하다`, `예측한다`와 같은 해석 술어를 배제하기 위해서다. |
| **4.3** | Favorable fixed-set의 `+0.016236`, `5/5`가 사후 선택 지위보다 앞서 보이면 confirmatory 결과처럼 읽힐 위험이 있었다. | 제목을 **고정 선택 집합 재학습과 acquisition 반복 결과**로 바꾸고, 목적·첫 문장·표 4-3·문단 순서·요약에서 결과 관찰 후 선택된 favorable set과 `POSTHOC_DESCRIPTIVE` 지위를 먼저 표시했다. | Fixed-set arm은 사후 기술 분석이며 selector 우위, confirmatory PASS 또는 acquisition 재현 성공의 근거가 아니기 때문이다. |
| **4.5** | 제목의 `양의 효과`가 success, 인과 효과 또는 실용적 개선을 선취할 수 있었다. | 제목을 **KSDD2 Dice 차이와 사전 최소효과 기준 판정**으로 바꾸고 Dice 차이·CI·결과 확인 전에 고정한 평균 기준의 미충족을 같은 관찰 단위로 유지했다. | 양의 방향과 사전 기준 미충족을 success/no-effect 이분법 없이 동시에 보고하기 위해서다. |
| **5.1** | “선택 단계의 양의 방향과 다운스트림 전체 기준 충족이 같은 판정을 만들지 않았다”는 문장이 제6장 6.1의 EP01 통합 결론과 기능상 중복되었다. | 세 분기의 미충족 지점이 **희소 클래스 지표·학습 방향·평균 최소효과 기준으로 서로 달랐다**는 해석과 분기 이질성, native metric 비합산, `0/3`의 비율 해석 금지만 남겼다. | 논의 장은 이질성과 제한 조건을 설명하고, 완결된 통합 문장은 결론 장에 한 번만 두기 위해서다. |
| **5.5·5.7** | Active annotation time, GPU-hour, energy, 금액 원장 부재와 비용 절감 불가가 두 절에서 반복되었다. | 5.5가 image count와 annotation effort/cost의 비등가성 및 미관찰 비용 자료를 상세히 담당하고, 5.7은 **이미지 예산의 비용 해석 제한은 5.5 참조**라는 교차참조만 유지하도록 축소했다. | 5.5의 전담 기능을 명확히 하고 5.7의 공통 한계 목록에서 동일 내용을 반복하지 않기 위해서다. |
| **5.6** | KSDD2의 selection 수치, LOO, positive seed fraction, pixel AP, FPR, run completeness를 다시 열거해 4.5와 중복되고 success/no-effect 오독 위험이 커졌다. | 직접 결과는 Macro Dice `+0.037565`, CI `[+0.019581,+0.057029]`, 결과 확인 전에 고정한 평균 `+0.05` 기준 미충족만 남기고 supporting·safety 수치는 **표 4-5 주 교차참조**로 대체했다. | 논의 장은 판정 수준과 외부 calibration 제한을 해석해야 하며 결과 장의 보조 수치를 재서술할 필요가 없기 때문이다. |

## 3. 파일별 반영 내역

### `chapter4_writing_packets_v2.md` / `chapter4_writing_packets_v2.csv`

- 4.1의 제목, 목적, 첫 관찰, 허용·금지 표현, 한 문장 요약을 관찰형으로 좁혔다.
- 4.3의 첫 제시 순서를 `사후 선택 및 POSTHOC_DESCRIPTIVE 지위 → fixed-set 관찰 → acquisition 반복 관찰 → 사전 기준 판정`으로 고정했다.
- 4.3의 표 4-3 연결 문구에도 favorable set의 사후 재학습 지위를 표시했다.
- 4.5의 제목에서 `양의 효과`를 제거하고 Dice 차이와 사전 최소효과 판정을 병렬로 유지했다.
- 4.2와 4.4의 claim, 수치, 장 역할은 변경하지 않았다.

### `chapter5_writing_packets_v2.md` / `chapter5_writing_packets_v2.csv`

- 5.1의 목적·허용 해석·요약에서 제6장과 동등한 결론형 술어를 제거했다.
- 5.5에 비용·annotation-time·계산 자원·금액 관련 상세 한계를 집중시켰다.
- 5.7에서는 비용 상세를 제거하고 5.5 교차참조만 남겼다.
- 5.6의 직접 결과 요약을 Dice·CI·사전 평균 기준 판정으로 축소하고 나머지는 표 4-5로 넘겼다.
- 5.2–5.4의 claim 강도와 해석 범위는 변경하지 않았다.

## 4. 유지한 방화벽

- 4.3의 fixed-set 결과는 항상 결과 관찰 후 선택된 favorable 사례의 `POSTHOC_DESCRIPTIVE` 분석으로 표시한다.
- 4.5와 5.6에서는 `양의 방향`을 success·우월성·실용적 개선으로, 사전 기준 미충족을 failure·no-effect로 번역하지 않는다.
- 5.1의 `0/3`은 이질적인 세 분기의 기술적 집계일 뿐 실패율이나 일반화 확률이 아니다.
- 5.7의 STOP branch에는 counterfactual learner outcome이 없으므로 downstream 성공·실패 또는 Gate 예측 정확도를 주장하지 않는다.
- 비용·annotation-time·GPU-hour·금액 절감은 관찰되지 않았고 5.5의 해석 제한으로만 다룬다.

## 5. 검증 기준

- 제4장 v2는 4.1–4.5의 다섯 절을 유지한다.
- 제5장 v2는 5.1–5.7의 일곱 절을 유지한다.
- CSV의 열 구조와 절별 행 수를 원본과 동일하게 유지한다.
- v2에 포함된 실험 수치는 각 원본 writing packet에 이미 존재하는 수치만 사용한다.
- EP01–EP05 밖의 새 claim을 추가하지 않는다.

## 수정 후 바로 초안 작성 가능한 절

- **4.1:** 관찰형 제목과 native endpoint 경계가 고정되었다.
- **4.2:** 기존 관찰·금지선이 유지되었다.
- **4.4:** 전체·frequent·rare 지표의 관찰 범위가 유지되었다.
- **5.2:** Learner outcome 부재 경계가 유지되었다.
- **5.3:** Fixed-set과 acquisition 재현성의 해석 대상이 분리되어 있다.
- **5.4:** Rare AP point estimate와 일반 harm 금지선이 유지되었다.
- **5.5:** 비용·annotation-time·예산 한계의 전담 위치가 확정되었다.

## 아직도 주의가 필요한 절

- **4.3:** 모든 실제 문단·표·그림 캡션에서 favorable fixed-set의 사후 선택과 `POSTHOC_DESCRIPTIVE`를 수치보다 먼저 보여야 한다.
- **4.5:** Dice의 양의 방향과 평균 `+0.05` 기준 미충족을 같은 문단에서 분리하지 말고, success/no-effect 표현을 사용하지 않는다.
- **5.1:** 미충족 지점의 차이와 분기 이질성만 해석하고 EP01의 완결된 관계 문장을 쓰지 않는다.
- **5.6:** Supporting·safety 수치를 본문에 다시 열거하지 말고 표 4-5를 교차참조한다.
- **5.7:** 비용 자료의 상세 목록을 되살리지 않고 5.5 교차참조만 둔다.

## 제6장 결론에서 한 번만 쓸 문장

> **선택 단계와 다운스트림 결과가 모두 관찰된 세 평가 분기에서, 선택 단계에서 양의 방향으로 나타난 결과만으로는 사전에 정한 다운스트림 평가 기준의 충족을 확인할 수 없었다.**
