# 제4장–제6장 교차 장 일관성 감사

## 감사 판정

현재 패킷은 핵심 claim의 범위와 금지선이 대체로 일치하므로 **조건부 통과**로 판정한다. 다만 초안 작성 전에 다음 세 원칙을 문장 수준에서 더 엄격하게 적용해야 한다.

1. **제4장 = 관찰:** 수치, 비교 방향, 신뢰구간, 시간적 지위, 사전 기준 충족 여부만 둔다.
2. **제5장 = 해석과 경계:** 제4장의 관찰이 무엇을 의미하고 무엇을 의미하지 않는지 설명하되, EP01의 최종 결론 문장을 선취하지 않는다.
3. **제6장 = 통합 1회:** EP02–EP05를 데이터셋이 포함된 짧은 문장으로 요약한 뒤 EP01 최종 문장을 6.1 마지막에 한 번만 둔다.

즉시 수정 우선순위는 다음과 같다.

- **높음:** 5.1–6.1의 EP01 중복, 4.3의 favorable fixed-set 오독, 4.5–5.6의 KSDD2 success/no-effect 이분법
- **중간:** 5.5–5.7의 비용·예산 한계 중복, 4.1 제목의 `타당성` 표현
- **낮음:** EP02·EP04의 제4장 수치를 제5장에서 과도하게 반복할 가능성

## 집중 충돌 감사

### 1. 5.1의 통합 해석과 6.1의 결론 문장 중복

- **현재 위험:** 높음
- **근거:** 5.1 `allowed_interpretation_1`은 EP01 최종 문장의 핵심 술어인 “선택 단계의 양의 방향과 다운스트림 기준 충족의 불일치”를 이미 완결된 결론으로 말한다.
- **역할 충돌:** 5.1이 결론을 확정하면 6.1은 같은 문장의 반복이 된다.
- **수정 제안:** 5.1에서는 세 분기의 미충족 지점이 희소 클래스 지표·학습 방향·평균 최소효과 기준으로 달랐다는 해석, `0/3`이 실패율이 아니라는 경계, native metric 비합산만 남긴다. EP01 최종 문장은 6.1 마지막에서만 쓴다.

### 2. 5.5와 5.7의 한계 서술 중복

- **현재 위험:** 중간
- **중복 내용:** Active annotation time, GPU-hour, energy, 금액 원장 부재와 비용 절감 불가가 두 절에 반복된다.
- **역할 분리:** 5.5는 `image count ≠ annotation effort/cost`를 상세히 설명하는 전담 절이다. 5.7은 공통 한계 매트릭스에서 “이미지 예산의 비용 해석 제한은 5.5 참조”라는 한 문장만 둔다.
- **수정 제안:** 5.7의 “제한된 비용 자료” 상세 목록과 비용 원장 설명을 삭제하고 5.5 교차참조로 병합한다. 5.7에는 post-hoc, pool, threshold, counterfactual, 이질성만 본문 핵심으로 남긴다.

### 3. 4.1의 전제 설명이 제5장 해석처럼 보일 위험

- **현재 위험:** 중간
- **위험 지점:** 제목 `후보 선택 신호의 타당성`은 측정 결과를 넘어 타당성 검증을 완료한 것처럼 읽힌다. “후보 신호는 양의 차이를 보였다”라는 summary도 downstream relevance와 연결될 수 있다.
- **수정 제안:** 제목을 `후보 선택 신호별 선택 단계 관찰` 또는 `후보 선택 신호의 선택 단계 측정 결과`로 바꾼다. 본문에는 native endpoint, Random 대비 방향, no pooling만 두고 `타당하다`, `유효하다`, `예측한다`는 술어를 사용하지 않는다.

### 4. 4.3의 favorable fixed-set 결과가 confirmatory처럼 읽힐 위험

- **현재 위험:** 높음
- **위험 지점:** `+0.016236`, `5/5`가 먼저 강조되면 결과를 확인한 뒤 선택된 favorable set이라는 시간적 지위가 약해진다.
- **수정 제안:** 제목을 관찰형으로 좁히고 첫 문장을 `사후 기술 분석`으로 시작한다. 표와 그림의 fixed-set 열에도 `POSTHOC_DESCRIPTIVE`를 넣는다. `confirmation`, `PASS`, `재현 성공`은 fixed-set arm에 사용하지 않는다.

### 5. 4.5–5.6에서 KSDD2가 success/no-effect 이분법으로 오독될 위험

- **현재 위험:** 높음
- **양방향 오독:** 양의 CI만 강조하면 success·우월성으로, `+0.05` 미충족만 강조하면 no-effect·실패로 읽힌다.
- **수정 제안:** 4.5는 Dice 차이·CI·mean rule 미충족을 같은 문단과 같은 표 행에 둔다. 5.6은 “통계적 방향”, “결과 확인 전에 고정한 기준 판정”, “외부 calibration”을 구분하되 4.5 수치를 전부 반복하지 않는다. 6.1 요약도 양의 방향과 기준 미충족을 한 문장 안에서 함께 유지한다.
