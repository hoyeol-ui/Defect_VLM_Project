# Claim-to-Outline Map

## 목적과 적용 원칙

이 문서는 채택된 최종 claim `EP01–EP05`를 현재 목차의 결과·논의·결론에 배치한다. Claim의 문장 강도, 수치, 근거 범위는 변경하지 않고 역할만 분리했다. `EP06`은 기존 C 판정을 유지해 부록 또는 본문 1문장 교차참조로만 처리한다.

장별 역할은 다음과 같이 고정한다.

- **제4장 실험 결과:** 관찰된 수치, 비교 방향, 신뢰구간, 사전 기준 충족 여부만 제시한다. 일반화·원인·방법론적 시사점은 말하지 않는다.
- **제5장 논의:** 왜 서로 다른 평가 대상이 같은 결론으로 합쳐질 수 없는지 해석한다. 결과 장의 수치를 새로 계산하거나 claim 강도를 높이지 않는다.
- **제6장 결론:** EP02–EP05를 반복 나열한 뒤 EP01의 통합 문장을 한 번만 제시한다. 새로운 근거·수치·인과 설명을 추가하지 않는다.

## 결과·논의·결론의 문장 기능 고정

### 결과 장에서의 문장 형식

결과 장의 EP02–EP05는 다음 순서만 허용한다.

1. 비교 대상·평가 단위 제시
2. 핵심 수치와 신뢰구간 또는 기준 제시
3. 관찰된 방향 또는 기준 충족 여부 진술
4. 대응 figure/table 참조
5. 다음 절이나 논의 장으로 이동

결과 장에서는 “따라서 평가 체계를 분리해야 한다”, “충분조건이 아니다”, “실무적으로 중요하다” 같은 해석 문장을 쓰지 않는다.

### 논의 장에서의 문장 형식

논의 장에서는 결과를 다시 계산하지 않고 다음 역할만 수행한다.

- EP02: discovery와 composition을 동일 성공 지표로 취급할 수 없는 이유
- EP03: training-seed 안정성과 acquisition 재현성을 분리해야 하는 이유
- EP04: 평균 성능과 희소 클래스 지표를 함께 보고해야 하는 이유
- EP05: 통계적 양의 방향과 사전 기준 충족을 구분해야 하는 이유
- EP01: 네 개 사례를 세 completed evaluation branch의 제한적 통합으로 묶고 일반화 경계를 명시

### 결론 장에서의 문장 형식

6.1에서는 EP02–EP05를 각각 한 문장으로 요약한 뒤 EP01을 마지막 문장으로 둔다. 수치 전체를 반복하지 않고 데이터셋명과 관찰 방향만 남긴다. 6.2에서는 claim을 다시 강화하지 않고 향후 독립 pool·threshold calibration 필요만 기술한다.

## 결과 장의 핵심 소절 순서

1. **4.1 후보 선택 신호의 타당성:** 후속 결과를 읽기 위한 전제만 제시하며 최종 claim은 배치하지 않는다.
2. **4.2 결함 발견량과 선택 집합 구성 — EP02:** MPDD와 VisA의 discovery 수치와 category coverage 결과를 병렬 제시한다.
3. **4.3 고정 집합 학습 안정성과 획득 재현성 — EP03:** Post-hoc fixed-set 결과를 먼저 표시하고 10-acquisition confirmation을 뒤에 둔다.
4. **4.4 전체 성능과 희소 클래스 성능 — EP04:** GC10 q20의 overall·frequent·rare 지표를 같은 표와 그림에서 제시한다.
5. **4.5 통계적 양의 효과와 사전 최소효과 기준 — EP05:** KSDD2의 양의 Dice 차이, CI, 사전 `+0.05` 기준 미충족을 함께 제시한다.

EP01은 제4장의 개별 소절이나 소절 제목으로 사용하지 않는다. 제4장 말미에는 “개별 평가 결과의 통합적 해석은 제5장에서 제시한다”는 전환 문장만 둔다.

## 논의 장에서만 말할 해석

- **5.1 / EP01:** 세 completed evaluation branch의 관찰을 묶어, 양의 방향의 선택 단계 결과만으로 다운스트림 기준 충족을 확인할 수 없었다고 해석한다. `0/3`을 실패율로 부르지 않는다.
- **5.2 / EP02:** 결함 발견량과 선택 집합의 범주 구성은 서로 다른 평가 대상이라고 해석한다. MPDD·VisA의 learner outcome은 언급하지 않는다.
- **5.3 / EP03:** 고정 집합의 training-seed 안정성과 acquisition 반복 재현성은 대체 가능한 개념이 아니라고 해석한다. Independent pool 일반화는 부정도 긍정도 하지 않고 미확인으로 둔다.
- **5.4 / EP04:** Average detector metric과 희소 클래스 지표를 함께 보고해야 한다고 해석한다. Rare-class harm의 인과성·통계적 확정은 말하지 않는다.
- **5.6 / EP05 및 EP01:** 통계적 양의 방향, 사전 기준 충족, 외부 실용성은 서로 다른 판정이라고 해석한다. `+0.05`의 산업적 최적성, selector 우월성, framework 예측 정확도는 말하지 않는다.

## 결론 장에서만 말할 통합 문장

6.1의 마지막 문장은 다음으로 고정한다.

> **선택 단계와 다운스트림 결과가 모두 관찰된 세 평가 분기에서, 선택 단계에서 양의 방향으로 나타난 결과만으로는 사전에 정한 다운스트림 평가 기준의 충족을 확인할 수 없었다.**

이 문장은 EP02–EP05의 데이터셋별 결과를 먼저 요약한 뒤에만 사용한다. 초록에서도 같은 범위 제한을 유지한다. “선택 단계의 gain은 downstream utility의 충분조건이 아니다”라는 더 일반적인 명제로 바꾸지 않는다.

## 현재 목차에서 수정이 필요한 번호/제목

필수적인 장 번호 변경은 없다. 제4장 4.2–4.5와 제5장 5.2–5.4는 EP02–EP04에 이미 잘 대응한다. 다만 다음 제목 수정이 필요하다.

1. **5.1 제목 수정 권고**
   - 현재: `선택 단계 근거와 다운스트림 학습 효용의 관계`
   - 수정: `평가 분기별 선택 단계 결과와 다운스트림 기준 충족의 관계`
   - 이유: EP01이 세 평가 분기의 제한적 합성임을 제목에서 드러내고 보편 관계로 읽히는 것을 막는다.
2. **5.6 제목 수정 권고**
   - 현재: `선택 단계와 다운스트림 성능 간 연결의 제한 조건`
   - 수정: `선택–학습 연결 해석의 범위와 제한 조건`
   - 이유: 5.1과의 중복을 줄이고 EP05의 threshold calibration 및 EP01의 일반화 제한을 담당하게 한다.
3. **부록 A 제목 구체화 권고**
   - 현재: `추가 평가 분기 및 보조 표`
   - 수정: `추가 평가 분기(GC10 K40/140) 및 보조 표`
   - 이유: EP06의 위치를 고정하고 본문 핵심 claim과 혼합되는 것을 방지한다.
4. **4.1과 5.5의 역할 주의**
   - 4.1과 5.5에는 채택된 최종 claim이 직접 배치되지 않는다. 두 절을 유지하되 새로운 핵심 claim을 생성하거나 EP01을 분산 배치하지 않는다.
