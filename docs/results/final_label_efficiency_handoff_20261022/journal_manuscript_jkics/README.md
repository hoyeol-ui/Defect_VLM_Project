# 한국통신학회논문지 원고

학술지의 연구 질문은 Frozen DINOv2 표본 선택과 10~35% 이미지 라벨 예산의 검출 성능, 그리고 100% 지도학습 참조 대비 도달률이다.

- `manuscript/JKICS-FrozenDINOv2-LabelEfficiency-20261021.docx`: 현재 공식 투고 양식에서 작성한 익명 편집 원고.
- `manuscript/JKICS-FrozenDINOv2-LabelEfficiency-20261021.md`: 본문 텍스트 대조본. Word 최종 편집과 동기화 필요.
- `figures/JKICS-research-flow-en.svg`, `.png`: 내부 영문 투고용 흐름도. Word에는 PNG 삽입, SVG는 편집용.
- `submission_check/20261021_JKICS_review.md`: 지침 차이, 유사 게재 논문 3편, 작성 범위와 미완료 작업.
- `work/`: 출처·원본 양식·생성 코드·문서 QA. 독립 렌더러는 시스템 설치나 연구 Python 패키지 변경 없이 이 안에 추출했다.

결과 수치는 고정 평가 후에만 입력한다. 대시와 대괄호 문구는 평가 대기 표시다. 현재 파일은 제출 완료본이 아니다. 학위논문 이력 및 원본 초안은 기존 위치와 `../thesis_manuscript/README.md`의 구분에 따라 보존한다. 학술지 편집 과정에서 실험 프로토콜·분할·예산·모델·반복 횟수를 바꾸지 않는다.
