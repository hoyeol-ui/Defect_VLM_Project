# 투고용 그림

`JKICS-research-flow-en.svg`는 벡터 편집본, `.png`는 Word 삽입본이다. 모든 내부 표기는 영문이며 AL과 100% 참조를 별도 경로로 보여 준다. 순차 실행 원장이나 모델의 실제 실행 순서를 그린 그림이 아니다. 논문 캡션은 Word에서 국·영문을 병기한다.

평가 후 만들 학습곡선은 두 데이터셋의 실제 누적 이미지 수를 x축, mAP50-95 (%)를 y축으로 하고 Random / DINOv2-FF / Entropy의 평균±표본 SD를 표시한다. 공유 10%는 동일 결과를 사용한다. Full의 평균과 SD는 별도 참조선/대역으로 표시하고 nAULC 적분에는 넣지 않는다. 결과가 없으므로 곡선을 미리 생성하지 않았다.

클래스별 AP와 도달률 그림도 실제 집계값에서만 만든다. 모든 축·범례·표 내부는 영문, 차이는 percentage points, 도달률은 percent로 명시한다. 기존 `docs/figures/20261021_research_flow.svg`는 교수님 설명용 국문 그림으로 유지한다.
