# 학위논문 관리

이 디렉터리는 학위논문과 학술지 원고의 관리 경계를 기록한다. 기존 학위논문 원본을 이동하거나 덮어쓰지 않았다.

학위논문은 기존 연구 이력과 검증 과정을 보존한다. 초기 VLM 탐색, C224와 F518의 데이터 정의 차이, YOLOv8 결과, 분할 및 테스트 노출 감사, 신규 YOLO26s 실험군을 구분한다. 과거 방법 설명의 YOLOv8을 전역 치환하거나 두 검출기의 반복을 합산하지 않는다.

기존 근거 문서:

- `../docs/20261021_final_experiment_protocol.md`
- `../docs/20261021_thesis_paper_plan.md`
- `../docs/20261021_paper_draft.md`: 10월 21일 공통 내용 초안으로 보존. 학술지 최신 편집 원본은 별도 경로를 사용.

학술지 편집 원본은 `../journal_manuscript_jkics/manuscript/JKICS-FrozenDINOv2-LabelEfficiency-20261021.docx`이다. Frozen DINOv2의 표본 선택과 라벨 효율에 집중하고 기존 연구 이력은 필요한 한계 문맥으로만 간결히 설명한다.

두 문서의 최종 수치는 동일한 고정 평가 원자료에서 가져오고, 서로 다른 실험군·분할·반복·개발/테스트 지표를 합치지 않는다. 학위논문 최종 Word의 새 장·표 반영은 모델 및 평가 완료 후 별도 편집으로 수행한다.
