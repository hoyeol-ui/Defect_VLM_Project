# 제한된 라벨 예산에서 Frozen DINOv2 기반 표본 선택의 금속 표면 결함 검출 학습 효율 분석

작성일: 2026.10.21. **학습 진행 중인 내용 초안**이다. 학회 제출 양식·분량·저자 정보는 미확정이며, 기존 학위논문 원본을 대체하지 않는다. 서론·관련 연구·연구 방법을 먼저 작성하고 결과 수치는 고정 평가 완료 후 채운다. 최근 YOLO26 결과와 기존 YOLOv8 결과는 별도 실험군으로 기술한다.

## 1. 서론

금속 표면 결함 검사는 제품 품질과 공정 상태를 확인하는 작업이다. 영상 기반 객체 탐지는 결함의 종류와 위치를 함께 예측할 수 있어 이러한 검사에 활용할 수 있다. GC10-DET는 실제 산업 환경의 금속 표면에서 수집한 열 가지 결함을 다루며, NEU 표면 결함 데이터는 열연 강판의 여섯 유형에 대해 클래스와 위치 주석을 제공한다. 이들 공개 자료는 결함 검출 방법을 비교하는 연구 기반을 제공한다. [GC10 원 논문](https://www.mdpi.com/1424-8220/20/6/1562), [NEU 공식 데이터 설명](https://faculty.neu.edu.cn/songkc/en/zdylm/263265/list/)

검출기를 지도학습하려면 이미지별 클래스뿐 아니라 결함 영역의 위치 주석이 필요하다. 따라서 제한된 라벨로 검출 성능을 확보하려면 학습에 포함할 영상을 선택하는 문제를 함께 고려해야 한다. 라벨이 없는 후보 중 일부를 선택하고 주석을 확보한 뒤 검출기를 다시 학습하는 풀 기반 능동학습은 이 문제를 다루는 한 가지 접근이다. 같은 수의 이미지를 사용하더라도 어떤 영상을 선택하는지에 따라 학습 자료의 구성과 예측 성능이 달라질 수 있다.

표본 선택에는 검출기가 불확실하게 예측하는 이미지를 우선하는 방법과, 특징 공간에서 기존 선택 표본과 다른 영상을 추가하는 방법 등이 있다. 불확실성 선택은 현재 검출기의 예측에 의존하고, 특징 기반 선택은 어떤 표현과 거리로 영상 간 차이를 측정하는지에 의존한다. 따라서 한 방법의 점수가 높게 나온 사례만으로 선택 전략의 일반적인 우위를 판단하기보다, 동일한 학습·평가 조건에서 라벨 예산에 따른 변화와 반복 간 변동을 함께 확인할 필요가 있다.

본 연구는 Frozen DINOv2 특징 기반 farthest-first 선택을 Random 및 검출기 class-score Entropy와 비교한다. 비교 예산은 전체 학습 풀의 약10%,15%,20%,25%,30%,35%이며, 별도로 같은 검출기를 전체 학습 풀의100%로 학습한 참조 모델을 둔다. 같은 예산에서 방법 간 차이가 있는지와,35% 라벨에서 전체 학습 참조 성능의 어느 정도를 확보하는지를 함께 분석한다. 학습곡선과 정규화 면적(nAULC)을 주 지표로 사용하고,35% 도달률·클래스별 AP·보조 검출 지표를 제시한다.

본 연구의 기여는 다음 세 항목으로 정리한다. 첫째, 두 공개 결함 데이터의 고정 분할에서 세 선택 전략을 같은 검출기와 라벨 예산으로 비교한다. 둘째, 전체 학습 풀 기준을 포함하여 제한된 라벨에서 확보한 성능을 상대적 도달률과 절대 차이로 제시한다. 셋째, 대응된 반복과 선택 원장을 이용해 평균 성능뿐 아니라 변동과 Entropy 동점 처리의 영향을 함께 해석한다. 새로운 검출기나 선택 알고리즘의 개발을 기여로 주장하지 않는다.

## 2. 관련 연구

### 2.1 산업 표면 결함 검출과 비교 조건

산업 표면 영상에는 결함 크기·형태·배경 질감의 차이가 존재한다. 같은 이름의 공개 데이터셋을 사용한 연구라도 정제 규칙, 학습·개발·테스트 이미지, 검출기 크기 및 평가 IoU 범위가 다르면 보고 성능의 의미가 달라진다. 본 연구는 외부 성능을 맥락 자료로 사용하되, 선택 전략의 주 비교는 내부의 동일 조건에서 수행한다.

2026년10월1일 공개된 Jeong·Song의 자료는 GC10-DET와 NEU-DET의 stratified70/15/15 분할, YOLOv8·YOLO11·YOLO12·RT-DETR 실행 기록과 분석 코드를 제공한다. 해당 자료는 실험 조건을 확인할 수 있다는 점에서 유용하지만, 본 연구의 관계 component 기반 분할과 canonical 처리의 일치가 확인된 것은 아니다. 원문은 투고 논문을 위한 공개 데이터·코드로 소개되어 있어 게재가 확정된 논문으로 인용하지 않는다. [공개 자료와 서지](https://zenodo.org/records/23073155)

### 2.2 특징 공간의 대표성과 다양성 선택

Sener와 Savarese는 CNN의 능동학습을 core-set 선택 관점에서 다루었다. 이러한 관점은 특징 공간에서 표본의 대표성을 고려하여 학습 집합을 구성하는 근거를 제공한다. 본 연구는 고정된 영상 표현에서 현재 라벨 집합과의 최근접 거리가 큰 영상을 차례로 추가하는 greedy farthest-first를 사용한다. 원 논문의 최적화 절차나 이론적 성질을 본 실험에 그대로 증명한 것으로 해석하지 않는다. [Core-set 연구](https://arxiv.org/abs/1708.00489)

DINOv2는 대규모 영상으로 사전학습한 범용 시각 특징을 제공하는 자기지도 학습 연구다. 본 연구는 학습된 DINOv2-small을 고정하여 영상 표현을 추출하고, 특징 추출기를 갱신하지 않은 상태에서 표본 선택에 사용한다. 검출기는 별도의 YOLO26s이며, DINOv2를 검출기 backbone으로 결합하지 않는다. 텍스트 입력을 사용하지 않는 시각 표현 기반 선택으로 범위를 명확히 한다. [DINOv2 원 논문](https://arxiv.org/abs/2304.07193)

### 2.3 검출기 불확실성과 이미지 단위 Entropy

이미지 분류와 달리 객체 탐지에서는 한 이미지에 여러 후보 박스와 클래스 점수가 나타난다. 이미지 단위 불확실성을 계산하려면 후보 처리와 여러 객체의 점수 집계 규칙이 필요하다. 본 연구는 사전에 사용한 normalized class-score mean entropy 규칙을 유지한다. 각 박스의 sigmoid class score를 합이1이 되도록 정규화한 뒤 클래스 수로 정규화한 Shannon entropy를 계산하고, 남은 후보 박스의 평균을 이미지 점수로 사용한다.

이 점수는 검출기 출력에 기반한 선택 지표이며 보정된 사후확률이나 인식적 불확실성의 직접 추정이라고 가정하지 않는다. confidence 기준을 넘는 예측이 없는 영상의 점수는0으로 정의한다. 그 결과 동점 집합이 생길 수 있으므로, 정확 점수와 ID 순서의 고정 규칙을 따르면서 동점·예측 없음·ID 순위 통계를 별도로 기록한다. 알고리즘은 데이터나 결과를 본 뒤 변경하지 않는다. 구현 근거는 고정한 `entropy.py`, `entropy_adapter.py`와 선택 원장이다.

### 2.4 본 연구의 비교 범위

동일한 검출기에서 선택 전략만 달리하는 비교와, 검출기를 변경한 과거 연구군 사이의 차이를 구분한다. 기존 YOLOv8의 결과는 연구 이력과 참고 결과로 남기며 새로운 YOLO26 반복과 합산하지 않는다. 동일한 epoch 정책에서100% 학습은 더 많은 이미지와 업데이트를 포함하므로, 이 참조값은 동일 계산량의 비교나 성능의 절대 상한을 뜻하지 않는다.

## 3. 연구 방법

### 3.1 데이터와 고정 분할

본 실험은 기존 F518 단계에서 고정한 데이터 버전을 사용한다. GC10-DET의 eligible canonical 표본은2,291장, NEU-DET는1,798장이다. 각 표본의 RGB identity와 주석 정합성, 알려진 중복·부분 영상 관계 및 보수적으로 묶은 위험 관계를 고려한 component 분할을 유지한다. component는 물리적 제품이나 생산 lot의 정답 그룹을 의미하지 않는다.

| 데이터셋 | 클래스 수 | 학습 풀 | 개발 | 테스트 | 분할 seed |
|---|---:|---:|---:|---:|---:|
| GC10-DET | 10 | 1,604 | 343 | 344 | 2026091906 |
| NEU-DET | 6 | 1,258 | 270 | 270 | 2026091907 |

이미지 ID와 component가 현재 분할을 가로지르지 않는지 원장으로 확인한다. NEU에는 기존 `ANNOTATION_PATCH_v2_0_2`에 따라 동일 클래스·동일 좌표의 정확 중복 bbox3행을 제거한 실행 라벨을 사용한다. 원본 이미지·주석을 새로 대체하거나 추가 정제하지 않는다. 학습·개발 입력6,950개 이미지 및 라벨 파일의 SHA-256과 분할 ID를 착수 전에 재검증했다.

초기 C224 연구의 GC10 학습 풀1,605장 및70/10/20 분할은 위 표와 별도다. 본문에서는 원본 파일 수·canonical 표본 수·분할별 이미지 수를 구분한다. 현재 고정 테스트는 과거 연구에서 평가한 이력이 있으므로, 연구 전 과정에서 미관찰인 신규 테스트라고 기술하지 않는다.

### 3.2 라벨 예산과 반복

라벨 예산의 분모는 선택 가능한 학습 풀의 이미지 수다. 개발·테스트 이미지는 이 풀에 포함하지 않는다. 약10%를 초기 라벨 집합으로 두고, 다섯 차례의 획득을 통해35%까지 증가시킨다.

| 표시 예산 | 10% | 15% | 20% | 25% | 30% | 35% |
|---|---:|---:|---:|---:|---:|---:|
| GC10 누적 이미지 | 160 | 241 | 321 | 401 | 481 | 561 |
| NEU 누적 이미지 | 126 | 189 | 252 | 315 | 377 | 440 |

반복은 세 개의 대응된 획득·학습 seed 설정으로 구성한다. 획득 seed는2026091901/1902/1903이며 이에 대응하는 learner seed는2026091900/1908/1909다. 같은 반복 안의 Random, DINOv2-FF, Entropy는 초기 라벨 집합과 learner seed를 공유한다. 각 learner seed에 대응하는100% 참조도 한 번 학습한다. 이는 세 개의 결합 반복이며 획득과 학습 무작위성의 효과를 분리하는3×3 설계가 아니다.

### 3.3 Random과 Frozen DINOv2-FF

Random은 기존 protocol의 PCG64/SeedSequence namespace·dataset code·획득 seed·round·purpose 조합으로 생성한 선택 목록을 계승한다. 초기 집합과 이후 무작위 선택의 purpose를 구분하며, 라벨 풀 밖의 이미지나 이미 선택한 이미지를 다시 추가하지 않는다.

DINOv2-FF는 고정 revision의 `facebook/dinov2-small`을 사용한다. 영상의 긴 변을518로 맞추고 고정 RGB값으로 패딩한 후, 마지막 CLS 표현을384차원의 L2 정규화 특징으로 저장한다. 현재 라벨 집합에 대한 최근접 특징 거리를 유지하고, 그 값이 가장 큰 영상을 추가할 때마다 거리를 갱신한다. 계산은 저장된 float32 특징을 float64 비교에 사용하며 기존 동률 허용범위와 ID 규칙을 유지한다. 검출기에 의존하지 않는 기존 선택 manifest72개를 SHA와 membership으로 확인하여 재사용하고 특징 추출이나 선택을 다시 튜닝하지 않는다.

### 3.4 Entropy 획득과 출력 검증

각 획득은 직전 예산에서 학습한 해당 반복의 YOLO26s best checkpoint로 수행한다. 남은 학습 풀의 이미지만 입력하고 후보의 정답 라벨·개발 성능·테스트 정보는 점수 계산에 사용하지 않는다. YOLO26s의 one2one branch에서 top-k 처리 이전의 전체 클래스 sigmoid score를 확보한다. 설치 버전에서 박스는 XYXY로 복호화되므로 기존 entropy 함수가 기대하는 XYWH로 좌표만 변환한다.

기존 규칙에 따라 최대 클래스 score가0.25를 넘는 후보를 고려하고, 클래스별 stable NMS의 IoU 기준0.7과 최대300개를 적용한다. 후보별 정규화 entropy의 평균이 이미지의 획득 점수다. 후보가 없으면0이며, 이미지 점수가 정확히 같으면 opaque ID 오름차순으로 선택한다. 이 후보 정리는 entropy 집계에 사용하는 내부 처리로, 검출기 최종 평가의 one2one 경로와 구분한다.

획득 기록에는 부모 checkpoint와 입력 해시, 이미지별 raw tensor 해시·검출 수·점수·선택 목록을 포함한다. 예측 없음 비율, 정확 동점 비율, cutoff 동점에서 ID 규칙으로 선택된 비율, ID 순위10분위 분포를 기록한다. 일부 이미지는 반복 추론으로 일치를 확인한다. 전체 후보가 같은 점수로 퇴화하거나 출력·집합 검증에 실패하면 원인을 보고하고 후속 학습을 중단한다. 사후 대체 선택 규칙은 적용하지 않는다.

### 3.5 YOLO26s 학습과100% 참조

공통 검출기는 공식 사전학습 `yolo26s.pt`에서 시작한다. 각 예산의 모델은 동일한 공개 가중치로 새로 초기화하며 이전 예산의 학습을 이어받지 않는다. 설정은100 epoch,640 입력, batch8, nbs64, SGD(lr0=.01,lrf=.01,momentum=.937,weight_decay=.0005), cosine schedule, warmup3, close_mosaic10이다. 나머지 증강·손실 설정은 봉인한 공통 kwargs를 따른다. 초기화·epoch·optimizer·입력 해상도 등을 방법별로 바꾸지 않는다.

best checkpoint는 학습 중 개발 분할의 mAP50-95가 최대인 epoch로 정하고 동률이면 마지막 epoch를 선택한다. 해당 loader는 batch16·rect=True다. 최종 보고 평가는 FP32, batch8,640,rect=False,conf=.001,IoU=.7,max_det300을 사용한다. 학습 중 checkpoint 선택 점수와 별도 보고 평가의 AP를 구분한다. Ultralytics8.4.90의 실제 one2one 경로를 사용하며 다른 버전의 기본값을 소급하지 않는다.

100% 참조는 같은 train pool 전체를 사용하고 나머지 학습·평가 정책을 공유한다. GC10의 learner seed2026091900 모델은 같은 환경·설정·데이터·가중치 해시와100 epoch 완료를 검증하여 재사용한다. 저장된 개발 AP를 테스트 AP로 옮겨 쓰지 않는다. 전체 설계102개 정규 셀 중 이1개를 제외한101개를 새로 실행한다. 기술 점검은 별도의 이력으로 남기고 과학적 반복에 포함하지 않는다.

### 3.6 평가지표와 통계

주 검출 지표는 mAP50-95이며 mAP50·Precision·Recall·클래스별 AP를 보조로 제시한다. P/R는 설치된 validator가 smoothed mean F1 최대점에서 반환하는 요약값이며 고정confidence 운영점과 구분한다. 예산별 성능과 반복별 nAULC를 계산하고 세 대응 설정의 평균±표본 표준편차(ddof=1)를 보고한다.

nAULC는 여섯 실제 누적 이미지 수에 대한 성능곡선을 사다리꼴 적분한 뒤 마지막과 첫 라벨 수의 차이로 나눈 값이다.100% 참조는 이 적분에 포함하지 않는다. 35% 도달률의 주 요약은 평균mAP35를 평균mAPFull로 나눈 백분율이며, 같은 learner seed에 대응하는 개별 비율의 평균±SD 및 절대 gap(%p)도 별도로 보고한다. 두 종류의 평균비를 혼동하지 않고 분모가0이면 비율을 정의하지 않는다.

DINO−Random과 DINO−Entropy의 반복별 nAULC 차이를 대응 비교한다. 두 데이터셋·두 비교의 네 primary family에 Holm 정의를 적용한다. 세 대응 반복의 양측 exact sign-flip 검정에서 가능한 최소p는.25이므로 통계적 우위를 확인했다는 결론을 내릴 수 없다. 효과량·방향·표준편차·반복별 원자료를 중심으로 기술한다. 예산 여섯 지점을 독립 반복으로 세지 않는다.

### 3.7 실행 재현성과 테스트 사용

실행 환경은 Python3.11.9, Torch2.12.1+cu126, torchvision0.27.1+cu126, Ultralytics8.4.90, RTX3070으로 고정한다. 패키지 버전과 함께 설치된 수치 소스·학습 소스·kwargs·입력·선택 목록의 SHA를 봉인한다. GPU 작업은 lock으로 직렬화하고 셀마다 고유 출력, 실제 epoch·학습시간·checkpoint 해시·성공/실패를 기록한다. 실패 시 배치·AMP·학습률·예산을 자동 변경하지 않는다.

NEU Full과 두 데이터셋의 공유10%를 우선 실행하고, 공유 모델의 Entropy 획득 검증을 통과한 뒤 나머지 행렬을 순차 실행한다. 전체 모델과 설정 확정 후 별도 평가 목록으로 고정 테스트를 평가한다. test 결과를 보고 검출기·선택 방법·예산·주 지표를 다시 고르지 않는다. 과거 테스트 열람과 이전 분할에서의 학습 노출 이력은 한계에 명시한다.

## 5. 한계 문단 초안

본 비교는 공개된 두 결함 데이터의 하나의 고정 분할과 지정 검출기 설정에 한정된다. 개발 분할은 설정 검토와 checkpoint 선정에 사용되었고, 고정 테스트에는 과거 연구의 평가·자료 사용 이력이 있다. 따라서 연구 전 과정에서 미관찰인 외부 환경의 확증으로 해석하지 않는다. 세 대응 seed 설정은 획득과 학습 무작위성의 결합 변동을 관측하며 두 요인의 효과를 분리 추정하지 않는다. 또한 고정epoch의100% 참조는 더 많은 학습 업데이트를 포함하므로 동일 계산량 비교가 아니다. 이미지 비율은 bbox 수나 실제 annotation 소요 시간과 같지 않다.

## 학위논문 반영 메모

기존3.5절의 YOLOv8n 서술을 문서 전체에서 일괄 치환하지 않는다. 기존 v8 결과를 설명하는 방법·결과는 유지하고, 새로운26 실험군의 설정과 반복을 별도 소절·표로 연결한다. 기존4.5절과 표4-4의 Full 비교를 확장하여 새26 참조·도달률·SD를 구분한다. 초기 VLM 탐색과 C224/F518의 연구 이력은 학위논문에서 보존한다. 본 초안의 출처와 번호는 실제 학회·학위논문 참고문헌 양식이 정해진 뒤 원고 전체와 대조한다.
