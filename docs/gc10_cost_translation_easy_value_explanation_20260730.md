# GC10 Cost-Translation 연구를 쉽게 설명하기

## 한 문장으로 말하면

저는 Active Learning 알고리즘이 “좋은 이미지 20장을 골랐다”고 말하는 데서 멈추지 않고, 그 20장을 사람이 실제로 작업할 때 시간이 얼마나 걸리고, 결함을 얼마나 빠뜨리며, 그렇게 만든 라벨로 학습한 모델이 같은 작업시간 안에서 정말 더 좋아지는지, 그리고 전체 평균 성능이 좋아져도 희귀 결함을 놓치는 위험은 커지지 않는지를 끝까지 확인하는 연구를 하고 있습니다.

## 처음 만난 다른 분야 교수님께 설명한다면

Active Learning은 모든 데이터를 사람이 다 라벨링하지 않고, 컴퓨터가 먼저 “지금 가장 가치 있어 보이는 데이터”를 골라 사람에게 보여 주는 방법입니다. 보통 논문에서는 Random이 고른 이미지 20장과 어떤 알고리즘이 고른 이미지 20장을 비교하고, 알고리즘 쪽으로 학습한 모델이 더 좋아지면 그 선택방법이 효율적이었다고 결론을 내립니다. 그런데 산업 결함 이미지에서는 이미지 한 장이 사람에게 요구하는 작업량이 전혀 같지 않습니다. 어떤 이미지는 크고 분명한 결함 한 개만 표시하면 끝나지만, 다른 이미지는 아주 작은 결함 여러 개를 확대해서 찾고 각각 box를 그리고 서로 비슷한 결함 종류를 구분해야 합니다. 두 경우 모두 논문에서는 “이미지 한 장”으로 계산되지만 실제 공장이나 데이터 구축 현장에서는 필요한 인력시간과 실수 가능성이 크게 다릅니다.

그래서 이 연구가 묻는 핵심은 “DINO가 Random보다 더 좋은 20장을 골랐는가?”가 아닙니다. 더 정확한 질문은 “DINO가 같은 20장을 골랐을 때 보였던 이점이, 실제 사람이 투입되는 시간으로 예산 단위를 바꾸어도 남아 있는가?”입니다. DINO가 rare defect나 여러 결함이 들어 있는 이미지를 더 많이 고른다면 선택 단계에서는 매우 좋아 보일 수 있습니다. 하지만 그런 이미지가 사람이 처리하기 훨씬 어렵다면 같은 20장이라도 더 많은 시간이 필요할 수 있고, 작은 결함을 빠뜨리거나 class를 잘못 지정할 수도 있습니다. 그러면 이미지 수 기준의 효율은 사람시간 기준에서는 사라질 수 있습니다. 반대로 조금 더 오래 걸리더라도 그 시간 안에 훨씬 유용하고 안전한 label을 만든다면 실제 가치가 있을 수 있습니다. 따라서 selection, human burden, label quality, learner utility를 한 단계씩 연결해야 합니다.

## 왜 학술적으로 가치가 있는가

이 연구의 학술적 가치는 새로운 selector 공식을 하나 더 제안하는 데 있지 않습니다. 이미 Active Learning에는 uncertainty, diversity, core-set, foundation model feature, pseudo-label 같은 수많은 선택방법이 있습니다. 더 큰 문제는 논문에서 사용하는 예산 단위가 실제 비용을 얼마나 잘 대표하는지 충분히 확인하지 않은 채, 같은 이미지 수를 같은 비용으로 간주하는 경우가 많다는 점입니다. 이미지 수는 계산하기 쉽고 실험도 편리하지만, object detection의 실제 annotation은 box 개수, 결함 크기, class ambiguity, 확대와 수정 횟수, 누락검사와 review에 따라 비용이 달라집니다. 따라서 “20장 대 20장”이라는 비교가 공정해 보여도 사람노동을 기준으로는 불공정할 수 있습니다.

이 연구는 그 간극을 측정 가능한 변수로 바꿉니다. 각 이미지에서 `IMAGE_START`, box 생성·이동·크기조절·삭제, class 지정·변경, pause/resume, submit을 기록하고, 단순히 창을 열어 둔 wall time과 실제 active time을 분리합니다. 또한 빠르게 끝냈다는 사실만으로 효율적이라고 판단하지 않고, reference box와 Hungarian matching을 수행하여 false negative, box recall, localization IoU, class accuracy, 작은 결함 recall, 희귀 결함 recall, adjudication correction time을 함께 봅니다. 그 다음 동일한 사람시간 \(T\) 안에서 실제로 완성된 human label만 사용하여 learner를 학습하고, 전체 mAP뿐 아니라 rare-class safety까지 확인합니다. 즉, selection metric과 downstream metric 사이에 있던 사람의 작업과 label noise를 연구대상 안으로 가져옵니다.

또 하나의 학술적 가치는 통계 단위를 정직하게 다루는 데 있습니다. 기존 GC10 결과에서 DINO는 서로 다른 acquisition seed에서도 같은 이미지들을 자주 반복해서 골랐습니다. Primary seed 5–14에서 Random은 200개 query slot에 187개 unique image를 사용하지만, DINO는 200개 slot이 51개 unique image에 집중됩니다. 이런 상황에서 seed 10개를 독립표본 10개로 단순 취급하면 같은 이미지의 작업시간이 여러 번 반복되어 가짜 표본 수가 늘어날 수 있습니다. 그래서 이번 protocol은 unique image를 cluster로 두고, 동일 이미지가 여러 batch에 포함되는 membership을 bootstrap 안에서 함께 움직이도록 설계합니다. 이 부분은 단순히 결과를 더 복잡하게 만드는 것이 아니라, 선택집합의 중복이 큰 AL 연구에서 불확실성을 과소평가하지 않기 위한 핵심적인 실험설계입니다.

그리고 prospective boundary도 학술적으로 중요합니다. DINO 후보와 과거 learner 결과는 이미 보았기 때문에 이 연구를 새로운 후보의 완전한 사전검증이라고 부를 수 없습니다. 대신 앞으로 아직 보지 않은 human-time, human-label quality, equal-time learner, rare safety endpoint와 STOP rule을 먼저 고정합니다. 이렇게 하면 결과가 마음에 들지 않을 때 time budget, idle cutoff, minimum effect, safety margin을 바꾸는 일을 막을 수 있습니다. 좋은 결과를 만드는 것보다 결과가 좋든 나쁘든 해석할 수 있는 실험을 만드는 것이 이 연구의 엄밀성입니다.

## 왜 산업적으로 가치가 있는가

산업 현장에서 중요한 것은 “라벨 이미지 수를 몇 장 줄였는가”보다 실제로 몇 사람-시간이 들었고, 그 시간 동안 몇 개의 결함을 정확히 처리했으며, 중요한 희귀 결함을 놓치지 않았는가입니다. 공장 데이터 구축 비용은 단순 이미지 수가 아니라 작업자 시간, 검수시간, 수정시간, 도구 설정시간, GPU 학습시간, 그리고 잘못된 label 때문에 다시 발생하는 비용의 합입니다. 이 연구가 사람의 active time과 adjudication time을 분리해 측정하는 이유는, 어떤 selector가 annotation 단계에서는 빨라 보여도 review와 correction을 많이 요구하면 전체 공정비용은 오히려 증가할 수 있기 때문입니다.

이 결과는 실제 데이터 구축 계획에도 직접적인 정보를 줄 수 있습니다. 예를 들어 DINO가 20장의 이미지 안에서 더 많은 defect box와 rare class를 발견하지만 Random보다 두 배 가까운 작업시간이 필요하다고 가정하면, 생산관리자는 “이미지 20장”이라는 예산표가 틀렸다는 사실을 알게 됩니다. 반대로 같은 60분 동안 DINO가 더 적은 이미지를 처리하더라도 더 많은 유효 defect와 더 좋은 learner 성능을 확보하고 rare safety까지 지킨다면, 사람시간 기준으로는 DINO가 더 가치 있는 선택일 수 있습니다. 이처럼 equal-time 결과는 라벨링 인력 배치, annotation session 길이, review 인력 규모, selector compute를 포함할지 여부, 그리고 AL을 실제 workflow에 넣을지 판단하는 근거가 됩니다.

산업적 측면에서 특히 중요한 것은 희귀 결함 안전성입니다. 기존 GC10 development 결과에서는 DINO가 Random보다 전체 mAP50–95를 약 `+0.0174` 높이고 recall도 개선했지만, rare-class macro AP는 약 `−0.0199` 낮았습니다. 평균 성능만 보면 성공처럼 보이지만, 상대적으로 드문 결함에서 성능이 나빠졌다면 품질검사 시스템에서는 받아들이기 어려울 수 있습니다. 평균적으로 더 많은 불량을 찾는 것과, 비용이 큰 희귀 불량을 안전하게 찾는 것은 같은 질문이 아닙니다. 이번 연구가 overall utility와 rare safety를 별도 gate로 두는 이유가 바로 이것입니다. 산업에서는 평균 1~2%의 개선보다 특정 치명적 결함의 누락 한 건이 훨씬 큰 손실을 만들 수 있기 때문입니다.

또한 실패 결과도 산업적으로 유효합니다. 만약 DINO가 선택 단계에서 rare image를 더 많이 확보했지만 실제 사람시간을 고려하면 효율이 사라진다면, 기업은 복잡한 selector와 embedding compute를 도입하기 전에 멈출 수 있습니다. 만약 사람시간에서는 이득이 있지만 rare recall이 떨어진다면, 전체 처리량을 위해 안전성을 희생하는 정책임을 알 수 있고 도입을 중단하거나 별도의 human review가 필요한 지점을 찾을 수 있습니다. 만약 시간·품질·learner·rare safety를 모두 통과한다면 그때 비로소 다음 lot이나 site에서 외부 재현을 검토할 정당성이 생깁니다. 즉, 이 연구는 성공한 알고리즘을 홍보하는 실험이라기보다, 값비싼 다음 단계로 넘어갈지 말지를 결정하는 위험관리 실험입니다.

## 결과별로 무엇이 남는가

### 1. 동일 시간에서도 학습이득과 희귀 안전성이 모두 유지되는 경우

GC10이라는 제한된 조건 안에서 DINO의 equal-image advantage가 실제 human-time과 human label을 거쳐 learner utility로 번역되었다고 말할 수 있습니다. 이때도 다른 공장에 바로 적용할 수 있다고 말하는 것이 아니라, 외부 lot/site 검증으로 넘어갈 근거가 생겼다고 말해야 합니다.

### 2. 전체 학습성능은 좋아지지만 희귀 안전성이 실패하는 경우

선택전략이 평균적인 효율은 높였지만 중요한 소수 결함을 희생했다는 뜻입니다. 이것은 실패한 실험이 아니라 “전체 효율”과 “산업 안전”을 분리해야 한다는 강한 근거입니다. 운영에서는 추가 검수비용까지 포함해야 하므로, 겉으로 보이는 mAP 이득이 실제 비용이득이 아닐 수 있습니다.

### 3. 사람시간을 넣자 selection advantage가 사라지는 경우

이미지 수가 비용의 좋은 대리변수가 아니었다는 뜻입니다. Active Learning 논문에서 편리하게 사용하던 image budget이 실제 object-detection annotation burden을 왜곡할 수 있음을 보여 줍니다. 이는 selector 실패만이 아니라 평가단위의 실패입니다.

### 4. 사람시간은 줄지만 label quality가 낮아지는 경우

빠르게 처리된 것이 효율이 아니라 누락과 부정확한 box에서 나온 것일 수 있습니다. Review와 adjudication까지 포함하면 절감이 사라질 수 있으므로, annotation speed를 quality와 분리해서 보고해서는 안 된다는 결론이 남습니다.

### 5. 차이가 거의 없는 경우

GC10의 현재 조건에서는 복잡한 DINO selector가 Random보다 실무적으로 의미 있는 비용차이를 만들지 못했다는 결론입니다. 이것도 중요한 결과입니다. 계산비용과 구현복잡성이 추가되는 방법을 도입하지 않아도 된다는 의사결정 근거가 되기 때문입니다.

## 과장하지 말아야 할 부분

이 연구는 아직 public GC10 fixed pool을 사용하고, annotator도 현실적으로 2명 또는 4명 수준이며, 다른 제품·lot·camera·공장으로의 외부 재현을 하지 않았습니다. 따라서 실제 제조비용을 절감했다고 말할 수 없고, DINO가 일반적으로 Random보다 우수하다고 말할 수도 없습니다. 정확한 주장은 “GC10의 한정된 조건에서, 이미 확인된 후보의 선택이점이 실제 사람시간·label quality·동일시간 학습·희귀 안전성으로 번역되는지를 사전 동결된 방식으로 측정했다”입니다.

이 제한을 분명히 하는 것은 연구를 약하게 만드는 것이 아니라, 산업 적용에서 가장 위험한 과장, 즉 공개 데이터셋의 작은 평균성능 차이를 곧바로 생산효율이나 비용절감으로 바꾸어 말하는 오류를 피하게 합니다.

## 발표용 30초 설명

“Active Learning 연구는 보통 이미지 20장을 골랐으면 동일한 annotation budget을 썼다고 가정합니다. 그런데 산업 결함 detection에서는 이미지마다 결함 개수와 크기, 분류 난이도가 달라 사람 작업시간과 누락위험이 크게 다릅니다. 저는 DINO가 Random보다 좋아 보였던 GC10 선택결과를 대상으로, 실제 이미지별 active time과 box 수정행동, 작은·희귀 결함 누락, human label로 학습한 동일시간 detector 성능까지 연결해서 검증하려고 합니다. 핵심은 새 selector를 만드는 것이 아니라, 이미지 수 기준의 이점이 실제 사람시간과 안전성을 거쳐도 유지되는지를 사전 동결된 protocol로 확인하는 것입니다.”

## 발표용 2분 설명

“현재 Active Learning 논문에서는 어떤 방법이 Random보다 더 유용한 이미지 20장을 골랐고, 그 20장으로 학습한 모델이 더 좋아졌다면 효율적인 방법이라고 평가하는 경우가 많습니다. 하지만 object detection에서 이미지 한 장의 비용은 동일하지 않습니다. 명확한 결함 한 개가 있는 이미지와 작은 결함 여러 개를 찾아 각각 box와 class를 지정해야 하는 이미지는 둘 다 한 장이지만 실제 사람시간과 오류가능성은 전혀 다릅니다.

저희 GC10 결과에서도 DINO는 반복적으로 특정 visual prototype과 rare/multilabel 이미지를 더 많이 선택했고, 전체 mAP와 recall은 Random보다 좋아졌습니다. 하지만 rare-class AP는 오히려 낮아졌습니다. 그래서 평균성능만으로는 이 선택이 산업적으로 좋은지 판단할 수 없습니다.

다음 실험에서는 먼저 이미지별 start, pause, box 생성·수정·삭제, class 변경, submit을 기록해서 실제 active time을 측정합니다. 동시에 사람의 box를 reference와 매칭해 누락, 위치정확도, class 정확도, 작은 결함과 희귀 결함 recall을 봅니다. 그런 다음 같은 이미지 수가 아니라 같은 사람시간 안에 완성된 label로 detector를 학습하고 overall mAP와 rare safety를 함께 평가합니다.

이 연구의 학술적 가치는 selection과 learning 사이에 있던 human burden과 label noise를 직접 측정하는 데 있고, 산업적 가치는 단순 이미지 수가 아니라 사람시간·검수시간·희귀 결함 위험을 기준으로 AL 도입 여부를 판단할 수 있게 하는 데 있습니다. 결과가 좋으면 외부 lot 검증으로 넘어갈 근거가 생기고, 결과가 나쁘면 복잡한 selector와 GPU 실험에 더 투자하지 않아도 된다는 근거가 남습니다.”
