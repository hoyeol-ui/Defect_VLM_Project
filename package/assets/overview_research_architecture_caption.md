# 대표 연구 개요 도식 캡션

**그림 X. 산업 결함 Active Learning에서 선택 단계 신호와 다운스트림 학습 효용 간 연결에 대한 연구 개요.**

본 도식은 논문을 bounded empirical audit로 규정하고, selection-stage evidence, discovery와 selected-set composition, 고정 선택 집합의 training-seed 안정성과 동일 fixed pool에서의 acquisition reproducibility, downstream learner utility, 희소 클래스 지표의 별도 판정 및 endpoint-specific criterion을 구분해 제시한다. MPDD와 VisA는 learner outcome이 `NOT_AVAILABLE`인 선택 단계 평가이며, NEU-DET의 favorable fixed-set 결과는 `POSTHOC_DESCRIPTIVE`이다. GC10 q20과 KSDD2는 각각 전체·희소 클래스 지표의 상반 방향과 Dice 차이·결과 확인 전 최소효과 기준의 구분을 보여준다. Appendix A의 GC10 K40/140은 NUM-111 상태-only 패치와 `expansion not authorized` 지위를 유지한 보조 평가다. 분기별 native metric은 합산하지 않으며, 도식은 특정 selector의 일반적 우월성이나 독립 production pool 일반화를 뜻하지 않는다.

권장 배치: 제3장 3.1 전체 연구 설계 말미 또는 발표 자료의 연구 설계 개요 슬라이드. 제4장의 개별 결과 그림을 대체하지 않는다.
