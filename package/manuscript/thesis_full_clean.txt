1. 본 논문은 평가한 산업 결함 Active Learning 분기에서 selection-stage discovery, selected-set composition, fixed-set training stability, acquisition reproducibility, downstream learner utility, rare-class safety를 분리하고, 이들 사이의 연결이 어디까지 관찰되며 어디서 제한되는지를 정리한 bounded empirical audit이다.

## 국문초록

산업 결함 탐지에서는 희소·미세 결함과 전문가 판독 요구로 인해 labeled data 확보가 연구와 적용 모두의 병목으로 다뤄져 왔으며, Active Learning은 제한된 주석 예산 안에서 학습에 유용한 표본을 우선 선택하기 위한 접근으로 검토되어 왔다. 그러나 선택 단계에서 관찰되는 결과와 다운스트림 학습기 성능은 서로 다른 평가 단위와 조건에서 기록되므로, 하나의 선택 단계 지표만으로 후속 학습 결과의 판정을 대신할 수 있는지는 별도로 확인해야 한다.

본 연구는 새로운 selector의 제안이나 우월성 비교보다, 축적된 산업 결함 Active Learning 평가 분기에서 선택 단계 신호와 다운스트림 학습 효용 사이의 연결을 분기별 native endpoint와 증거 상태에 따라 재정리하는 데 목적을 둔다. 이를 위해 selection-stage discovery, selected-set composition, fixed-set training stability, acquisition reproducibility, downstream learner utility, rare-class safety와 결과 확인 전에 고정한 최소효과 기준을 구분된 평가 대상으로 두었다.

MPDD와 VisA의 동일한 물리적 fixed pool 내 200회 paired perturbation에서는 결함 이미지 발견량이 증가하였으나 선택 집합의 범주 구성 기준은 충족되지 않았다. 두 분기의 learner outcome은 NOT_AVAILABLE이며, 이는 다운스트림 성공이나 실패를 뜻하지 않는다. NEU-DET의 fixed-set 결과는 결과 관찰 후 선택된 favorable 사례의 POSTHOC_DESCRIPTIVE 분석이고 acquisition 반복은 동일한 물리적 fixed pool에서 수행되었다. 한 고정 선택 집합의 학습 seed 간 안정성은 선택 과정을 다른 acquisition seed에서 반복했을 때의 학습 효과 재현성과 동일하게 해석할 수 없었다. GC10 q20에서는 전체 mAP50-95가 증가한 반면 희소 클래스 macro AP는 감소하였다. KSDD2에서는 Macro Dice 차이와 신뢰구간 하한이 양의 방향으로 관찰되었으나 결과 확인 전에 고정한 평균 최소효과 기준은 충족되지 않았다.

이 결과는 평가한 데이터셋과 실험 분기 안에서 선택 단계의 발견량, 선택 집합 구성, 반복 단위, 전체·희소 클래스 지표, 사전 최소효과 기준을 서로 구분해 보고해야 함을 보여준다. 본 연구의 결론은 평가한 분기의 관찰 범위에 한정되며, 특정 selector의 일반적 우월성, 실제 비용 절감 또는 독립 production pool에 대한 일반화를 제공하지 않는다.

## 제1장 서론

### 1.1 연구 배경

산업 결함 탐지에서는 희소·미세 결함과 전문가 판독 요구 때문에 labeled data 확보가 연구와 실제 적용 모두에서 주요 제약으로 다뤄져 왔다. 결함 이미지의 상대적 희소성, 정상 이미지 대비 결함 이미지의 불균형, 그리고 결함 유형별 판독 난이도의 차이는 주석 작업의 단순한 물량 문제를 넘어 어떤 표본을 우선 확보할 것인가의 문제로 이어진다.

이러한 제약을 완화하기 위해 산업 결함 Active Learning 연구는 uncertainty 기반 sampling, diversity 기반 sampling, 두 관점을 결합한 hybrid sampling, 그리고 human feedback을 활용한 iterative labeling 방향으로 전개되어 왔다. 이들 접근은 대체로 label efficiency의 관점에서 같은 주석 예산 안에서 학습 성능을 얼마나 확보할 수 있는지를 평가한다.

최근에는 pretrained representation의 발전과 함께 Vision Foundation Model 및 Vision-Language Model의 표현을 사용해 unlabeled pool에서 표본을 선택하는 시도가 이어지고 있다. 이러한 접근은 image embedding의 유사도, cross-prompt response consistency, grounding 정합성 등의 신호를 acquisition 단계의 판단 근거로 사용한다.

선택 단계 지표와 다운스트림 학습 지표는 측정 단위와 평가 조건이 다르다. 산업 결함 데이터의 클래스 불균형, source 및 category 구성, 결함 유형별 판정 난이도와 다층적인 평가 지표를 고려하면, 선택 단계에서 양의 방향으로 기록된 결과와 후속 학습 기준의 판정을 분리해 확인할 필요가 있다.

### 1.2 연구 문제의 설정

기존 연구는 acquisition 결과가 seed, 초기 집합, query batch와 training protocol에 민감할 수 있음을 지적해 왔다. 또한 object detection Active Learning에서는 클래스 불균형과 희소 클래스 성능을 전체 성능 지표와 분리해 다뤄야 한다는 관점이 축적되어 왔다. VFM/VLM 기반 접근에서도 pretrained signal의 평가는 선택 단계의 측정 결과와 실제 learner 결과를 구분할 필요가 있다.

이러한 맥락에서 본 연구가 다루는 문제는 네 평가 질문으로 구성된다. 첫째, 선택 단계에서 관찰된 결함 이미지 발견량과 선택 집합의 범주 구성 결과가 같은 방향으로 기록되는지를 확인한다. 둘째, 하나의 고정 선택 집합을 여러 학습 seed로 재학습한 결과와 selector를 새로운 acquisition seed에서 다시 실행한 결과를 분리한다. 셋째, 다운스트림 전체 성능, 희소 클래스 지표와 사전 최소효과 기준의 판정을 병렬로 확인한다. 넷째, post-hoc 결과, fixed-pool 반복과 관찰되지 않은 learner outcome을 구분하여 현재 자료가 허용하는 해석 범위를 고정한다.

### 1.3 연구 목적 및 연구 질문

본 연구의 목적은 산업 결함 Active Learning에서 선택 단계 신호와 다운스트림 학습 효용 사이의 연결이 평가한 분기에서 어디까지 관찰되며 어디에서 제한되는지를 실증적으로 정리하는 것이다.

**자기 규정 1:** 본 논문은 평가한 산업 결함 Active Learning 분기에서 selection-stage discovery, selected-set composition, fixed-set training stability, acquisition reproducibility, downstream learner utility, rare-class safety를 분리하고, 이들 사이의 연결이 어디까지 관찰되며 어디서 제한되는지를 정리한 bounded empirical audit이다.

연구 질문은 다음과 같다.

1. **RQ1 — 선택 단계:** 평가한 산업 결함 AL 분기에서 후보 선택 신호의 Random 대비 결과는 해당 지표가 관찰된 분기의 discovery 및 selected-set composition 지표에서 어떻게 나타나는가?
2. **RQ2 — 반복 단위:** 고정 선택 집합의 training seed 반복 결과와 selector를 다시 실행하는 acquisition seed 반복 결과는 각각 어떤 변동성을 보여 주는가?
3. **RQ3 — 후속 평가:** 선택 단계 결과와 downstream learner utility, aggregate 성능, 희소 클래스 지표 및 사전 최소효과 기준의 판정은 해당 결과가 관찰된 평가 분기에서 어떻게 함께 또는 다르게 나타나는가?
4. **RQ4 — 증거 경계:** Post-hoc 결과, fixed-pool 반복, learner outcome의 NOT_AVAILABLE, 결과 확인 전에 고정한 기준을 구분할 때 현재 자료가 허용하는 선택–학습 연결 해석의 범위는 어디까지인가?

이들 연구 질문은 개별 평가 단위의 관찰뿐 아니라, 선택 단계에서 양의 방향의 결과가 나타난 분기에서 사전에 정한 다운스트림 평가 기준이 어떤 판정을 내렸는지를 평가 분기별로 함께 확인하도록 구성하였다. 이 예고문은 EP01이 RQ3과 RQ4의 통합 답변으로 회수될 위치를 지정하지만 결과를 선취하지 않는다.

### 1.4 연구 범위와 논문 구성

본 연구의 범위는 평가한 산업 결함 데이터셋(MPDD, VisA, NEU-DET, GC10, KSDD2)과 그 위에서 수행된 selection–learning 실험 분기에 한정된다.

**자기 규정 2:** 본 논문은 특정 selector의 일반적 우월성, 선택–학습 연결을 예측하는 검증된 framework, 산업 benchmark, 실제 비용 절감 또는 독립 production pool 일반화를 입증하는 연구가 아니다.

**자기 규정 3:** 본 논문의 기여는 새로운 선택 방법의 제안이 아니라, 평가한 분기 안에서 선택 단계와 후속 학습의 평가 단위 및 증거 상태를 분리하고 그 연결의 관찰 범위와 제한을 실증적으로 정리하는 데 있다.

본 논문은 다음을 다루지 않는다.

- 새로운 Active Learning selector 또는 보편적 평가 framework의 제안
- 실제 산업 현장의 주석 시간·인건비·GPU 비용 절감에 대한 정량 입증
- 독립 production 데이터 pool에 대한 일반화
- 특정 selector 또는 representation의 우월성에 대한 인과적 규명
- 희소 클래스 지표의 차이를 실제 산업 안전 위해 또는 rare-class harm의 인과적 증거로 해석하는 것

## 제2장 관련 연구

### 2.1 산업 결함 탐지와 데이터 주석화

산업 결함 탐지는 희소·미세 결함과 전문가 판독 요구 때문에 labeled data 확보가 병목이 되는 영역으로 다뤄져 왔다. 결함 유형별 물리적 특성 차이와 정상 이미지 대비 결함 이미지의 불균형은 데이터 수집과 주석 단계의 설계에 직접적인 영향을 준다.

산업 결함 Active Learning 연구는 uncertainty, category-aware sampling, hybrid sampling과 같은 접근을 통해 제한된 label에서 학습 성능을 확보하려는 문제에 초점을 두었다. 최근에는 explanation과 operator feedback을 활용해 sample 판정 근거와 human-in-the-loop 구조를 함께 고려하는 흐름도 나타난다. 본 연구는 이러한 접근의 재비교나 우열 판정을 목적으로 하지 않으며, 산업 결함 데이터에서 selection–learning 연결이 어느 조건에서 관찰되고 제한되는지를 평가 관점에서 다룬다.

### 2.2 객체 탐지 Active Learning

객체 탐지 Active Learning은 이미지 단위 분류와 달리 bounding box, 클래스와 위치 정합성 등 서로 다른 신호를 acquisition 판단에 반영해 왔다. 특히 클래스 불균형과 희소 클래스 성능은 detection AL 연구에서 반복적으로 지적되는 문제로, 전체 성능 지표만을 기준으로 삼는 평가가 특정 클래스의 성능 방향을 가릴 수 있다는 관찰이 축적되어 왔다.

본 연구는 새로운 rare-aware selector를 제안하지 않으며, 전체 성능 지표와 희소 클래스 지표를 별도의 평가 항목으로 병렬 보고한다. 여기서 rare-class safety는 실제 산업 안전을 뜻하지 않고 희소 클래스 지표를 전체 성능과 따로 확인하는 평가 항목이다.

### 2.3 VLM 및 시각 표현 기반 선택 신호

Vision Foundation Model과 Vision-Language Model 기반 접근은 pretrained representation을 활용해 unlabeled pool에서 표본을 선택하는 다양한 신호를 제안하고 있다. 이 흐름은 embedding 유사도 기반 다양성, prompt response 기반 uncertainty와 grounding 정합성 등의 신호를 acquisition 단계에서 활용한다.

본 연구는 새로운 prompt learning 또는 active finetuning 방법을 제안하지 않으며, 평가한 분기에서 pretrained signal의 선택 단계 결과와 학습기 결과를 분리해 기록한다. 따라서 특정 표현 모델의 보편적 유효성이나 선택–학습 연결의 인과 기제를 주장하지 않는다.

### 2.4 Active Learning의 평가와 재현성

Active Learning의 결과는 seed, 초기 집합, query batch와 training protocol에 민감할 수 있다는 지적이 축적되어 왔다. 이러한 지적은 fixed-set에서의 학습 안정성과 selector를 다시 실행하는 acquisition seed 반복이 서로 다른 조건부 질문임을 보여준다.

본 연구는 fixed-set training stability와 동일 fixed pool에서의 acquisition reproducibility를 분리해 관찰한다. 반복 결과는 사용한 pool과 protocol의 범위 안에서만 해석하며, 독립 production pool의 일반화 증거로 사용하지 않는다.

### 2.5 본 연구의 위치

본 논문은 평가한 산업 결함 Active Learning 분기에서 selection-stage discovery, selected-set composition, fixed-set training stability, acquisition reproducibility, downstream learner utility, rare-class safety를 분리하고, 이들 사이의 연결이 어디까지 관찰되며 어디서 제한되는지를 정리한 bounded empirical audit이다.

본 논문은 특정 selector의 일반적 우월성, 선택–학습 연결을 예측하는 검증된 framework, 산업 benchmark, 실제 비용 절감 또는 독립 production pool 일반화를 입증하는 연구가 아니다.

본 논문의 기여는 새로운 선택 방법의 제안이 아니라, 평가한 분기 안에서 선택 단계와 후속 학습의 평가 단위 및 증거 상태를 분리하고 그 연결의 관찰 범위와 제한을 실증적으로 정리하는 데 있다.

## 3.1 전체 연구 설계

본 연구의 설계는 평가한 산업 결함 데이터셋 각각에 대해 선택 단계와 다운스트림 학습 단계의 결과를 분리하여 기록하는 방식으로 구성되었다. 각 실험 분기는 데이터셋, 예산, 후보 선택 신호, 학습기, 지표 및 결과 확인 전에 고정된 판정 기준으로 정의된다. 서로 다른 분기의 native metric은 하나의 공통 효과크기로 합산되지 않았다.

## 3.2 후보 선택 신호

후보 선택 신호에는 Random baseline과 함께 uncertainty 계열, DINO 기반 embedding 다양성, hierarchical clustering 기반 diversity 및 Vision-Language Model 응답 관련 신호가 포함된다. 각 신호는 해당 평가 분기에서 정한 native endpoint를 기준으로 Random 대비 차이로 관찰되었다.

## 3.3 데이터셋 및 실험 분기

본 연구가 다루는 데이터셋과 실험 분기의 증거 상태는 다음과 같다.

- **MPDD:** selection-only audit; learner outcome은 NOT_AVAILABLE
- **VisA:** selection-only audit; learner outcome은 NOT_AVAILABLE
- **NEU-DET:** 결과 관찰 후 선택된 favorable fixed set의 POSTHOC_DESCRIPTIVE 재학습과 동일 fixed pool의 새로운 acquisition seed 반복
- **GC10 q20:** 5개 acquisition seed × seed별 3개 training seed의 downstream detector 평가
- **GC10 K40/140:** 부록 A의 보조 평가 분기
- **KSDD2 g5:** 결과 확인 전에 평균 Macro Dice 차이 +0.05 기준을 고정한 제한적 downstream learner 평가

## 3.4 선택 단계 평가

선택 단계 평가는 native endpoint의 Random 대비 차이와 해당 분기에서 정의된 기준 판정으로 구성된다. MPDD와 VisA는 candidate와 Random을 동일한 물리적 fixed pool 안에서 200회 paired perturbation으로 비교하였다. 이 반복은 독립 production pool의 반복이 아니다.

## 3.5 획득 재현성 평가

본 연구는 동일한 selected set을 여러 training seed로 다시 학습하는 fixed-set training stability와, selector를 동일한 물리적 fixed pool에서 다른 acquisition seed로 다시 실행하는 acquisition reproducibility를 구분한다. 두 평가는 변동의 원인이 되는 반복 단위가 다르다.

## 3.6 다운스트림 학습 효용 평가

다운스트림 학습 효용은 학습기의 전체 성능과 subgroup 지표를 병렬로 기록한다. GC10 q20에서는 overall mAP50-95, recall, frequent-class macro AP 및 rare-class macro AP를 구분한다. KSDD2에서는 Macro Dice를 primary endpoint로 사용하고 pixel AP와 정상 이미지 FPR 점검을 보조 항목으로 기록한다.

## 3.7 안전성 평가 지표 및 의사결정 기준

본 연구에서 rare-class safety는 희소 클래스 지표를 전체 성능과 별도로 확인하는 평가 항목을 의미한다. 실제 산업 안전 위험이나 rare-class harm의 인과적 입증을 뜻하지 않는다. KSDD2의 평균 Macro Dice 차이 +0.05 기준은 결과 확인 전에 고정되었으며, 통계적으로 양의 방향이 관찰되는지와 별도의 판정 항목이다.

## 5.2 결함 발견량과 구성 기준의 비일치

MPDD와 VisA의 선택 단계 평가에서는 결함 이미지 발견량 증가가 관찰되었지만 선택 집합의 범주 구성 기준은 충족되지 않았다. 이 관찰은 discovery와 selected-set composition을 같은 지표로 대신하지 않고 별도의 평가 항목으로 보고해야 하는 근거가 된다.

해석 범위는 두 데이터셋의 동일한 물리적 fixed pool 내 200회 paired perturbation에 한정된다. 두 분기의 learner outcome은 NOT_AVAILABLE이므로 이 결과를 downstream 실패, selector의 일반적 무효성 또는 독립 production pool의 재현성으로 확대하지 않는다.

## 5.3 고정 선택 집합의 training-seed 안정성과 동일 fixed pool에서의 acquisition reproducibility의 구분

NEU-DET의 favorable fixed set 결과는 결과 관찰 후 선택된 사례에 대한 POSTHOC_DESCRIPTIVE 재학습이다. 이 결과는 해당 selected set을 고정한 조건에서 training seed 변화에 따른 결과를 보여준다. 반면 acquisition 반복은 동일한 물리적 fixed pool에서 selector를 다시 실행할 때의 변동을 보여준다.

따라서 fixed-set training stability와 동일 fixed pool에서의 acquisition reproducibility는 서로 다른 조건부 질문이며, 하나의 결과가 다른 하나를 대체하지 않는다. 이 구분은 특정 selector가 재현에 실패했다는 결론이 아니며, favorable fixed set 결과를 confirmatory 근거로 승격하지도 않는다.

## 5.4 전체 성능과 희소 클래스 성능의 충돌 가능성

GC10 q20에서는 overall mAP50-95와 recall이 양의 방향으로 기록된 동시에 rare-class macro AP가 음의 방향으로 기록되었다. 이는 같은 평가 분기에서도 aggregate 지표와 subgroup 지표가 동일한 판정을 만들지 않을 수 있음을 보여준다.

여기서 rare-class safety는 희소 클래스 지표를 전체 성능과 별도로 확인하는 평가 항목이다. Rare-class macro AP에는 별도의 신뢰구간이 저장되어 있지 않으므로 이 결과는 한 평가 분기의 point estimate와 사전 기준 판정 범위에서만 해석하며, 실제 산업 안전 위해나 일반적인 rare-class harm의 인과적 증거로 확대하지 않는다.

## 5.5 이미지 예산 기반 평가의 한계

본 연구의 selection 평가는 대체로 이미지 수 예산에 기반한다. 이미지 수는 실제 주석 시간, 결함별 판독 난이도, bounding-box 수, 인건비 또는 GPU 비용을 직접 측정하지 않는다. 따라서 본 연구의 image-budget 결과는 정해진 이미지 수 안에서의 selection 관찰이며 실제 운영 비용 절감의 입증이 아니다.

이 한계는 비용·annotation-time·예산 문제를 다루는 중심 위치다. 5.7에서는 이 내용을 반복하지 않고, 본 절에서 규정한 범위 제한을 교차참조한다.

## 5.6 선택–학습 연결 해석의 범위와 제한 조건

KSDD2에서는 Macro Dice 차이의 신뢰구간 하한이 0을 초과했지만 결과 확인 전에 고정한 평균 +0.05 기준은 충족되지 않았다(표 4-5 참조). 이는 양의 방향의 통계적 관찰과 사전 의사결정 기준 충족이 서로 다른 판정임을 보여준다.

이 결과를 success와 no-effect의 이분법으로 읽어서는 안 된다. 양의 방향은 관찰되었고 사전 최소효과 기준은 충족되지 않았다는 두 상태를 함께 유지해야 한다. 또한 +0.05는 외부에서 보정된 산업 최적 임계값이 아니며, 관찰 범위는 KSDD2 한 acquisition pool과 한 학습기 설정에 한정된다.

## 5.7 연구의 한계

첫째, 현재 논문의 통합은 서로 다른 시기에 수행된 실험 분기를 사후적으로 정렬한 post-hoc integration이다. 공통 protocol로 동시에 설계한 다중 데이터셋 시험이 아니다.

둘째, MPDD와 VisA의 200회 paired perturbation 및 NEU-DET의 acquisition 반복은 동일한 물리적 fixed pool에서 수행되었다. 따라서 independent production pool 일반화를 제공하지 않는다.

셋째, fixed-pool perturbation은 seed 변화에 따른 조건부 변동을 보여주지만 생산 환경의 pool shift, 신규 결함 유형 또는 독립적인 수집 세션의 변동을 직접 평가하지 않는다.

넷째, KSDD2의 +0.05 기준은 결과 확인 전에 고정되었지만 외부 calibration 근거를 갖지 않는다. 기준 미충족은 효과 부재가 아니라 해당 사전 기준의 미충족이다.

다섯째, MPDD·VisA 및 DeepPCB를 포함해 learner outcome이 NOT_AVAILABLE인 분기의 counterfactual downstream outcome은 관찰되지 않았다. STOP branch를 downstream 실패로 포함하지 않는다.

여섯째, 이미지 예산과 실제 annotation-time·운영 비용의 차이는 5.5의 범위 제한을 따른다. 본 연구는 비용 절감을 정량 입증하지 않는다.
